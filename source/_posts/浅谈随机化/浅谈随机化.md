# SA

[blog](https://www.cnblogs.com/autoloop/p/15169642.html)

模拟退火 优化的随机化算法

1. 结果更优 直接转移
2. 结果更差 一定概率转移

选定一个初始状态（比如选定所有点坐标的平均数），选定一个初始温度 $T$

当温度大于一个边界值时：

1. 随机变化坐标，变化幅度为 $T$
2. 计算新解与当前解的差 $\Delta$
3. 如果新解比当前解优 ，就用新解替换当前解
4. 否则以 `exp(dt/T)` 的概率用新解替换当前解
5. 温度乘上一个小于 $1$ 的系数，即降温

这样，随着温度不断降低，变化幅度也越来越小，接受一个更劣的解的概率也越来越小

随机化的本地调试的时候不要加 while循环根本进不去 clock算上了人工输入数据的时间 肯定进不去

- 坐标系内：随机生成一个点，或者生成一个向量
- 序列问题： random_shuffle 或者随机交换两个数
- 网格问题：可以看做二维序列，每次交换两个格子即可

空间找点

序列排列

当每次 $calc$ 的复杂度 $\gt O(1000)$ 直接 $\text{random-shuffle}$，否则就交换两个数即可

参数 $(10^6,10^{-6},0.996)$，$(100,10^{-12},0.99864)$，$(10^4,10^{-6},0.997)$

## 空间找点

[模板题](https://www.luogu.com.cn/problem/P1337)

一切自然变化进行的方向都是使能量降低，因为能量较低的状态比较稳定

达到平衡稳态的时候，物体的总能量应该是最小的，即每个物体的重力势能之和最小

要想让某个物体势能减小，那就让拉着它的绳子在桌面下方的长度尽可能的长，也就是桌面上的要尽可能短

​	最小化 $\Sigma\,d_i\times m_i$

```C++
#include<bits/stdc++.h>
using namespace std;

const int N=1010;
struct node{
        double x,y,w;
}a[N];
node ans,res;
int n,step=2e4;

double calc(double x,double y)
{
    double res=0;
    for(int i=1;i<=n;i++)
    {
        double dx=x-a[i].x;
        double dy=y-a[i].y;
        res+=sqrt(dx*dx+dy*dy)*a[i].w;
    }
    return res;
}

double ner(double l,double r)
{
    return (double)rand()/RAND_MAX*(r-l)+l;
}

void SA()
{
    res.x=ans.x,res.y=ans.y;
    for(double t=20000;t>=1e-10;t*=0.996)
    {
        double dx=ner(res.x-step*t,res.x+step*t);
        double dy=ner(res.y-step*t,res.y+step*t);
        double dw=calc(dx,dy);
        double ned=dw-res.w;
        
        if(ned<0.0) //更优直接跳
        {
            res.x=ans.x=dx;
            res.y=ans.y=dy; //全局最优res只在这里更新
            res.w=dw;
        }
        else if(exp(-ned/t)>ner(0,1))
        {
            res.x=dx;
            res.y=dy;
        }
    }
}

int main()
{
    cin>>n;
    for(int i=1;i<=n;i++)
    {
        scanf("%lf%lf%lf",&a[i].x,&a[i].y,&a[i].w);
        ans.x+=a[i].x;
        ans.y+=a[i].y;
    }
    ans.x/=n,ans.y/=n;
    res.w=calc(ans.x,ans.y);
    res.x=ans.x,res.y=ans.y;
    
    while((double)clock()/CLOCKS_PER_SEC<0.85) SA();
    printf("%.3lf %.3lf",ans.x,ans.y);
    
    return 0;
}
```

## 序列排列

[模板题](https://www.luogu.com.cn/problem/P2503)

$n$ 个数分成 $m$ 组，求均方差 

假设有 $m$ 个队列，每次把该数加入和最小的队列中

虽然是假贪心但是作为模拟退火的评估函数很合适

random_shuffle 50->100

注意这里是交换前和交换后比较

```C++
#include<bits/stdc++.h>
using namespace std;

const int N=25;
int n,m;
double avg,ans;
int q[N],w[N];

double clac()
{
    memset(q,0,sizeof q);
    for(int i=1;i<=n;i++)
    {
        int idx=1;
        for(int j=1;j<=m;j++)
            if(q[idx]>q[j]) idx=j;
        q[idx]+=w[i];
    }
    double sum=0;
    for(int i=1;i<=m;i++) sum+=(double)(avg-q[i])*(avg-q[i]);
    ans=min(ans,(double)sum/m);
    return (double)sum/m;
}

double rand(double l,double r)
{
    return (double)rand()/RAND_MAX*(r-l)+l;
}

void sa()
{
    random_shuffle(a+1,a+n+1);
    for(double t=1e6;t>=1e-6;t*=0.996)
    {
        int k1=rand(1,n),k2=rand(1,n);
        double res1=clac();
        swap(w[k1],w[k2]);
        double res2=clac();
        double dt=res2-res1;
        if(exp(-dt/t)<rand(0,1)) swap(w[k1],w[k2]);
    }
}

int main()
{
    cin>>n>>m;
    for(int i=1;i<=n;i++) scanf("%d",&w[i]),avg+=w[i];
    avg/=(double)m;
    ans=clac();
    while((double)clock()/CLOCKS_PER_SEC<0.95) sa();
    //sa(),sa(),sa(),sa(),sa(),sa(),sa();
    printf("%.2lf",sqrt(ans));
    return 0;
}
```



[P7962 [NOIP2021\] 方差 - 洛谷 | 计算机科学教育新生态 (luogu.com.cn)](https://www.luogu.com.cn/problem/P7962)

首先 $D$ 乘个 $n^3$ 
$$
\begin{aligned} 
ans&=n^3D\\
&=\Sigma_{i=1}^{n} n^2(a_i-ave)^2\\
&=(na_i-\Sigma a_i)^2\\
\end{aligned}
$$
易证：对 $a_i$ 进行操作，等价于交换 $d_i\,d_{i+1}$ 

即除 $d_1$ 外，剩下的差分都可以随机交换

序列排列交换问题，可以用模拟退火

根据样例可以猜测，大概率这个答案的差分序列是呈单谷状，在开始退火之前，首先先把 $d$ 序列改为单谷的形式


这类序列问题，如果 $calc$ 的复杂度在 $O(1000)$ 级别了，就采用 $\text{random-shuffle}$ 的做法，不要随机换两个数

还是预处理可达点，然后设 $f_{i,j}$ 表示到了点 $i$，当前选了 $j$ 个点的最大权值和

 $f_{x,j} \gets f_{v,j-1}+w_x [p_i=x]$

考虑正确性，设答案为 $(a,b,c,d)$

每次不出现 $p_a \gt p_b \gt p_c \gt p_d$ 和 $p_a \lt p_b \lt p_c \lt p_d$ 的概率为 $\frac {2}{4!}=\frac{11}{12}$

则正确率为 $1-(\frac{11}{12})^T$ ，$T$ 为枚举次数

# 局部优化调整

[P7428 [THUPC2017\] 母亲节的礼物](https://www.luogu.com.cn/problem/P7428)

每个点随机染色，现在有非常多冲突

考虑局部优化调整算法

把每个点调整成和它相邻的点的颜色最少的那个颜色，记这个点为 $t$

这样调整，保证了 $4--4$ 这种同色边数量单调下降

同时这个调整还要考虑对 $t$ 的影响，然后算贡献最少的

我们这些调整丢到优先队列里面算就行了

```cpp
const int N=2.5e4+10;
int n,m,u,v;
int col[N],vis[N];
vector<int> as[N];
mt19937 Rand(99994919);

int rand(int l,int r)
{
	return Rand()/UINT_MAX*(r-l)+l;
}

int calc(int x)
{
	int res=0;
	go(v) {res+=(col[v]==col[x]);}
	return res;
}

void solve()
{
	n=fr(),m=fr();
	for(int i=1;i<=n;i++) as[i].clear();
	for(int i=1;i<=m;i++)
	{
		u=fr(),v=fr();
		as[u].pb(v),as[v].pb(u);
	}
	
	queue<int> q;
	memset(vis,0,sizeof vis);
	for(int i=1;i<=n;i++) col[i]=rand(0,3);
	for(int i=1;i<=n;i++)
		if(calc(i)>1) q.push(i),vis[i]=1;
	
	while(q.size())
	{
		int x=q.front();
		q.pop();
		vis[x]=0;
		if(calc(x)<=1) continue;
		
		int a[4]={0};
		go(v) a[col[v]]++;
		
		int mcnt=8,mcol=0;
		for(int i=0;i<=3;i++)
			if(mcnt>a[i]) mcnt=a[i],mcol=i;
		col[x]=mcol;
		go(v) {if(!vis[v] && calc(v)) q.push(v),vis[v]=1;}
	}
	
	for(int i=1;i<=n;i++)
		putchar(col[i]+'a');
	nl;
}
```
