$Sol.1$

设 $j$ 为使 $[j,i]$ 合法的第一个端点，则 $f_i \leftarrow f_j+1$

这个显然，考虑合法只有 $A(abba)$，$AB(abbacbbc)$，$xxABxx$ 几种情况

找直接暴力跳表，如果 $s_i=s_{i-1}$ 则 $j=i-1$，否则一直跳直到 $s_j=s_i$ ，没有设为 $-1$

考虑到这是一个字符匹配的过程，一个字符最多出现 $n$ 次，总复杂度 $O(26n)$

$Sol.2$

考虑 $Trie$ 维护这个 $j$

我们用到一个$JOI$ 的经典 $Trick$，维护区间等价于维护前缀！！

$s[x,y] \to s[1,y]-s[1,x-1]$ ，我们用栈维护这个过程，如果当前状态和之前的某个状态相同，则说明这一段消光了

这个状态可以用 $map$ 维护，或者 $Trie$

贴个 $Trie$ 的，就是先跑一个前缀，然后尝试弹栈

```cpp
cnt[0] = 1;
```

$Sol3$ 满足要求的点对数量，这很分治

考虑 $[l,r]$ ，显然是枚举左端点，然后考虑右端点贡献

维护前缀状态 $[l,mid]$ ，合法的后缀状态为两个都弹完相同元素后"相等"，直接 $Trie$ 维护即可

```cpp
int tot, now, s[N], tp;
struct Trie { int fa, s[26], cnt; } t[N];
void Add(int x) {
    if (tp && s[tp] == x)
        now = t[now].fa, --tp;
    else {
        if (!t[now].s[x])
            t[now].s[x] = ++tot,
            t[tot].fa = now;
        now = t[now].s[x];
        s[++tp] = x;
    }
    return ;
}
LL Solve(int l, int r) {
    if (l == r) return 0;
    int mid = l + r >> 1;
    LL res = Solve(l, mid) + Solve(mid + 1, r);
    now = tp = 0;
    F(i, mid + 1, r)
        Add(a[i]), ++t[now].cnt;
    now = tp = 0;
    dF(i, mid , l)
        Add(a[i]), res += t[now].cnt;
    F(i, 0, tot)
        t[i].fa = t[i].cnt = 0;
    tot = 0;
    return res;
}
```
