## 题目描述

小缘得到了一张地图。这张地图是一个 $1\sim n$ 的排列 $p_1,p_2,\cdots,p_n$，小缘可以从 $i$ 号点直接走到 $p_i$ 号点。

某天，小缘很抑郁，他就以**每个点**为起点，一直走，直到走回起点为止（若起点为 $v$，则他的走法为：$v\to p_v\to p_{p_v}\to\cdots$）。小缘记下了他走到每个点的次数（起点不算，终点算一次）。

这天，小缘不小心弄丢了地图，但他还记得他当天经过 $i$ 号点的次数为 $a_i$（$i=1,2,\cdots,n$）。小缘想要知道，有多少不同的地图能与他当天的记忆相符。

换句话说，有多少不同的排列，满足：

- 令 $v=1,2,\cdots,n$。
- 从 $v$ 号点开始，走到 $p_v$，再走到 $p_{p_{v}}$，$\cdots$，最后走回 $v$。
- 记录每个点被走到的次数（起点不算一次）。
- $i$ 号点被走到的次数恰好为 $a_i$。

由于答案可能很大，小缘只想知道答案对 $998244353$ 取模的结果。

### 输入格式

第一行一个整数 $T$，表示数据组数。

每组数据的第一行为一个正整数 $n$，表示排列的长度。

第二行为 $n$ 个正整数 $a_1,a_2,\cdots,a_n$，其中 $a_i$ 表示 $i$ 号点被经过的次数。

### 输出格式

对每组数据，输出一行一个整数，表示答案对 $998244353$ 取模的结果。

### 样例

```
2
6
1 1 1 1 1 1
6
6 6 6 6 6 6
```

```
1
120
```

### 样例解释

对于第一组数据，满足条件的排列只有 `1 2 3 4 5 6`。

对于第二组数据，其中一个满足条件的排列为 `2 3 4 5 6 1`。

### 限制与约定

对于 $20\%$ 的数据，$\sum n\le 10$。

对于 $40\%$ 的数据，$\sum n\le 200$。

对于 $70\%$ 的数据，$\sum n\le 5000$。

对于 $100\%$ 的数据，$1\le n,\sum n\le 5\times 10^5$，$1\le a_i\le n$。

------

一个点 $a_i=x$ 表示 $i$ 在一个大小为 $x$ 的置换环里面 ！！

我们计数 $cnt_x\,[a_i=x]$ ，有解 $x \mid cnt_x$

设 $k=\frac{cnt_x}{x}$ 问题转化为，有 $xk$ 个数，我们把他们分配成 $k$ 个环的方案数
$$
ans=(x-1)!^k \times \frac{ { xk \choose k } \times { (x-1)k \choose k } \times \ldots }{k!}
$$


前面是每个环内部的方案数，我们钦定 $a_1=1$ 为环头，比如 $sz=5$，就是求 $a_1 \to a_2 \to a_3 \to a_4 \to a_5 \to a_1$ 的方案数，这相当于是选边的方案数，$a_1 \to a_2$ 有 $4$ 条边，比如 $a_2=3$，则下一条边还有 $2\,4\,5$ 可以选，所以总共是 $(sz-1)!$

后面的分母显然，分子是因为比如选出来 $(1,2,3)\,(4,5,6)\,(7,8,9)$ 这样有 $3!$ 中排列方式

分母化简一下即可

```cpp
int F(int n,int k)
{
	int res=1;
	(res*=fac[n*k])%=Q;
	(res*=qkw(qkw(fac[n],Q-2),k))%=Q;
	(res*=qkw(fac[k],Q-2))%=Q;
	return res;
}

void solve()
{
	n=fr();
	for(int i=1;i<=n;i++) t[i]=0;
	for(int i=1;i<=n;i++) t[a[i]=fr()]++;
	int ans=1;
	for(int i=2;i<=n;i++)
	{
		if(t[i])
		{
			int x=t[i];
			if(x%i) {puts("0");return;}
			int k=x/i;
			(ans*=qkw(fac[i-1],k)%Q*F(i,k)%Q)%=Q;
		}
	}
	fw(ans),nl;
}
```
