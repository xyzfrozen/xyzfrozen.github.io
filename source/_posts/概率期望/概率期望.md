# 概率期望

# Chapter 1 概率定义

基本事件：某项随机试验发生的任何结果都称为一个基本事件
注意：基本事件可以是相对的

样本空间：所有基本事件的并集被称为样本空间，一般记作$Ω$

随机事件：若干个基本事件的并被称为一个随机事件，简称为事件

两个事件的并集记作或 $A∪B$
两个事件的交集记作 $A∩B$ 或 $AB$

仅满足 $A∩B = ∅$，则称 $A$ 和 $B$ 互不相容（或互斥）
如果 $A$ 的发生和 $B$ 的发生没有关系，则称 $A$ 和 $B$ 相互独立

事件 $A$ 发生的概率一般用 $P(A)$ 表示

常见的概率计算问题都是利用古典概型或者线性递推式，通过计算出合法方案数和总方案数，利用古典概型公式 P = 合法方案数/总方案数 或者 类似拓扑的 $dp$ 来求解

----------

$P(A \cup B)=P(A)+P(B)-P(AB)$

$P(AB)=P(A) \times P(B)$，$A\;B$ 相互独立时

定义 $P(A|B)$ 表示在已知事件 $B$ 发生的前提下事件 A 发生的概率，则 $P(A|B) = P(AB)/P(B)$

----------

设有 $n$ 个两两互不相容的事件 $A1, A2, . . . An$，且它们的并集 $Ω$，则对任意事件 $B\;A_k$

全概率公式 $P(B) = \Sigma _{i=1}^nP(A_i)P(B|A_i)$

贝叶斯公式 $P(A_k|B)=P(A_k)P(B|A_k)/P(B)=P(A_k)P(B|A_k)/(\Sigma _{i=1}^nP(A_i)P(B|A_i))$

# Chapter 2 基础题目

例题

**扔骰子问题 1**

有 $n$ 个六面骰子，投掷时，每个面朝上的概率均相同，且每个骰子的投掷结果相互独立。

现在投掷出这些骰子，请问恰好有 $m$ 个骰子的朝上面为一号面（仅有一个点的面）的概率是多少？

请你求出这个概率对 $998,244,353$ 取模的结果。

组合数学求解式

$ans=C_{n}^m \times (\frac{1}6)^m \times (\frac{6}{5})^{n-m}$

**扔骰子问题 2**

有 $n$ 个六面骰子，投掷时，每个面朝上的概率均相同，且每个骰子的投掷结果相互独立。

现在投掷出这些骰子，请问所有骰子朝上的面的点数之和恰好为 $m$ 的概率是多少？

请你求出这个概率对 $998,244,353$ 取模的结果。

$dp$ 求解式

$f_{i,j}$ 考虑前 $i$ 个骰子，和为 $j$ 的方案数

$f_{i,j}=\Sigma_{k=1}^j f_{i-1,j-k}$，$k$ 到 $j$ 主要是为了 $f_{1,[1 \to 6]}$，$f_{1,0}$ 显然为 $0$

$ans=f_{n,m}/6^n$

**搞笑世界杯**

有 $2n$ 个球，其中 $n$ 个红球，$n$ 个白球，$2n$ 个人排队领球，每人领一个。

到某人时，如果红球和白球都有剩余，则他有 0.5 的概率拿到红球，0.5 的概率拿到白球。

如果只剩一种颜色的球了，那么他必然领到那种颜色的球。

求最后两个人都领到同一种颜色的球的概率。

组合数学求解式

我们只考虑红球，剩下的拿白球，这样方案就不会重复

前 $n-2$ 个人恰好拿走 $n-2$ 或 $n$ 个红球，总方案就是 $2n$ 个人拿 $n$ 个红球

$(C_{2n-2}^{n-2}+C_{2n-2}^n)/C_{2n}^n$

$dp$ 求解式

$P(i,j)$ 发了 $i$ 个红球和 $j$ 个白球的概率

$P(i,j)=\frac{1}{2} (P(i-1,j)+P(i,j-1))$ 注意特判 $i,j$ 为 $0\;n$ 的情况

int main()
{

	{
		f[0][i]=0.5*f[0][i-1];

	}

# Chapter 3 期望定义

**随机变量** $X$ 的取值集合为 $S$，其中有 $x_1,x_2,.....x_n$，$X=x_i$ 的概率为 $P(x_i)$

定义期望 $E(X)=\Sigma_{i=1}^n x_i \times P(x_i)$

只能说某个值的期望，事件的期望没有意义

可以简单理解为加权平均数

性质

1 $E(C)=C$，$E(CX)=CE(X)$，$C$ 为常数

2 $E(XY)=E(X) \times E(Y)$，$X\;Y$ 互斥

3 $E(X_1+X_2+...+X_n)=E(X_1)+E(X_2)+...+E(X_n)$

4 $E(aX+b)=aE(X)+b\;(a,b\in R)$

期望题重点就是要找到事件是什么

这里指的事件代指期望中的随机变量

指示器随机变量求解就是三部曲：

1 设事件 $T$ 的指示器随机变量。

2 利用指示器随机变量和期望的线性性质分化问题。

3 求解事件 $T$ 发生的概率。

$I[X]$ 为事件 $X$ 的指示器随机变量。当事件 $X$ 发生时，$I[X]=1$，否则 $I[X]=0$

这样完成期望与概率的转换 $E(A)=P(A)$

同时，若一个事件发生的概率为 $p$，它期望在 $\frac{1}{p}$ 次后发生

**P1297 [国家集训队]单选错位**

本题的事件为正确答案和下一个正确答案是否相同，设为事件 $A$

显然 $E(A)$ 只与下一个数有关，同时我们发现这个概率和 $a_i$ 的大小有关，我们不妨分类讨论一下

$a_i \leq a_{i+1}$，前一个题选一个正确答案，后面选它，$$E(A)=\frac{1}{a_i} \times \frac{a_i}{a_{i+1}}=\frac{1}{a_{i+1}}$$

$a_i \gt a_{i+1}$，要想相同，前面一个题必须选后面的，$$E(A)=\frac{a_{i+1}}{a_i} \times  \frac{1}{a_{i+1}}= \frac{1}{a_i}$$

由期望的线性性，并且可以用指示器随机变量，设整个序列的事件为 $N$

$E(N)=E(A+...+A)=\Sigma E(A)$

$E(l_{i+1})=p(E(l_i)+1))$

$E(l^2_{i+1})=p(E(l^2_i)+2E(l_i)+1)$

$E(A)$ 就是 $E(l^3_{i+1})$，注意这是每个位置的贡献，我们还要加和

设当前拥有了 $i$ 件物品要获得 $n$ 件物品的期望次数为 $f_i$

$$\frac{n-i}{n}(f_{i+1}-f_i)=1$$

$$f_i=f_{i+1}-\frac{n}{n-i}$$

$$f_0=\Sigma_{i=0}^{n-1} \frac{n}{n-i}=\Sigma_{k=1}^{n} \frac{n}{k}$$

**P6835 [Cnoi2020]线形生物**

事件是走到哪条路上，考虑 $dp$

整个序列的事件 $N$ 是 $1 \to n+1$

设 $X_i$ 为从 $i$ 走到 $i+1$

$$N=X_1+X_2+..+X_n$$

$$E(N)=\Sigma E(X_i)$$

游走考虑直接到和间接到两种，设 $d_i$ 表示 返祖边的数量 $+1$

$$
\begin{gathered}
E(X_i) \leftarrow \frac{1}{d_i} \times 1\\
E(X_i) \leftarrow \frac{1}{d_i} \times \sum_{(i,v)} (E(X_v+..X_i)+1)\\
\end{gathered}
$$

先从 $(i,v)$ 走到 $v$ 再从 $v$ 走回 $i$

提出来 $E(X_i)$

$$
\begin{aligned}
E(x_i) &= \frac{1}{d_i} (1+\sum_{(i,v)} [(s[v,i-1]+1)+E(x_i) ]\\
&=\frac{1}{d_i} (1+\sum_{(i,v)} (s[v,i-1]+1)+(d_i-1)E(X_i))\\
&=d_i+\sum_{(i,v)} s[v,i-1]
\end{aligned}
$$

```cpp
const int N=1e6+10,Q=998244353;
int id,n,m,u,v,ans;
int d[N],f[N],s[N];
vector<int> as[N];

int main()
{
	id=fr(),n=fr(),m=fr();
	for(int i=1;i<=m;i++)
	{
		u=fr(),v=fr();
		as[u].pb(v);
		d[u]++;
	}
	
	for(int i=1;i<=n;i++)
	{
		f[i]=++d[i];
		for(auto v:as[i]) (f[i]+=(s[i-1]-s[v-1]+Q)%Q)%=Q;
		(s[i]+=f[i]+s[i-1])%=Q;
	}
	for(int i=1;i<=n;i++) (ans+=f[i])%=Q;
	fw(ans);

	return 0;
}
```
