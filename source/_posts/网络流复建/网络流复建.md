# 网络流复建

## 二分图

概念全部忘光光，省选全部寄光光

无向图 $(V,E)$ ，$A,B\subset V$，$A \cap B=\varnothing$，$A \cup B=V$，$\forall u,v\in A,\not \exists (u,v)\in E$，$\forall u,v\in B,\not \exists (u,v)\in E$

### 二分图判定

原图无奇环

除了常见的染色法，记一下一个好用的并查集方法，缺点是 $O(n\alpha(n))/O(n\log n) \gt O(n)$，但是在例如线段树分治中很好用

$\forall x\in V,x \to x,x'$，拆点，边全部转成出点到入点，判定就是 $x,x'$ 在同一冰茶姬内

可以发现这样对应到原图的路径一定是奇环，不是二分图



### 最大匹配

记最大匹配为 $M$，最大独立集为 $I$

$dinic$ 复杂度 $O(\sqrt nm)$

注：完备匹配 $|M|=\min(|A|,|B|)$



### Konig 定理

由于部分题目需要考这个构造过程，临时学一下

定理：二分图，最小点覆盖=最大匹配

以下为笔者自行证明，可能有不严谨的地方

我们跑最大流最小割，和 $s$ 联通的点集记为 $S$，和 $t$ 联通的点集记为 $T$

合法点覆盖可以是 $(S\,\cap\,B)\,\cup\,(T\,\cap A)$

如果存在边的两个点不属于上述点集，则既不和 $s$ 联通，也不和 $t$​ 联通这显然不符合最小割

接下来证明这是最小点覆盖，因为不存在一条边的两个点都在该点覆盖中，否则即和 $s$ 联通又和 $t$ 联通，而每条边至少有一个点在点覆盖中，这是最优情况，所以是最小点覆盖，换句话说，每个最小覆盖中的点对应一个最大匹配

所以，最大匹配=最大流=最小割=最小点覆盖

### Hall 定理

$V_1 \cup V_2=V$，$V_1 \cap V_2 =\varnothing$，$|V_1| \leq |V_2|$

二分图存在完美匹配的充要条件是 $\forall S\in V_1$，$S$ 中点连向 $V_2$ 中的点集并集 $S'$，$|S'| \geq |S|$

不会证啊

当然多重匹配也是容易证明的，不多赘述

推论

$|M|=|X|-\max (|X'|-|N(X')|)$

$X$ 为一边的点集，$X'$ 为一个子集，$N(X')$ 为子集的邻域

我们考虑先找最大匹配，然后把所有不在最大匹配中的点拿出来当做 $X'$，选出来恰好左侧点集比右侧点集大 $1$​，并集就多没有匹配的点数



广义 $\text{Hall}$ 定理

如果 $X \subseteq A,Y \subseteq B$ 都存在完美匹配，那么 $V=X\,\cup\,Y$​ 存在一个完美匹配

先找出一个覆盖 $X$ 部的 $A$ 集合的匹配，记它的边是 “红边”，再找出覆盖 $Y$ 部的 $B$ 集合的匹配，记它为 “绿边”。根据匹配的定义，一个点的邻边中，最多有一条红边、一条绿边

既然度数只有 $2$ ，对于每一个连通块，要么是环，要么是链

如果是环，只保留其中的红边或者绿边，显然可以覆盖这个连通块

如果是链

长度为奇数，那就保留第一个颜色 (端点的邻边的颜色) 的边，就可以覆盖这个连通块

长度为偶数的链，则两个端点同在 $X$ 或 $Y$ 部，而邻边的颜色不同，所以必定有一个是不需要被覆盖的，保留另一个 (必须被覆盖的点) 的邻边颜色的所有边



### Dilworth 定理

偏序集可以简单理解为 `DAG`，偏序就是重新定义 $\leq$ ，$a \leq b$ 则有 $a \to b$ 的边

偏序集中的链就是图的链，反链就是任意两个元素两两不连通

偏序集的最长反链大小等于最少可重链覆盖，在 `DAG` 中就是最大独立集等于最小可重路径覆盖



### 性质

最小点覆盖：选择最小点集，满足每条边至少有一个端点在所选集合中

最大独立集：选择最大点集，满足两两之间没有边相连

最小边覆盖：选择最小边集，覆盖原图点集，含孤立点的图没有边覆盖

团：原图的一个子图，其点集中任意两点有边相连

最大团：点集最大的团

补图：$V(G')=V(G)$，$\forall u,v\in V,(u,v)\in E,(u,v)\not \in E'$，$\forall u,v\in V,(u,v)\not \in E,(u,v) \in E'$

DAG 最小不相交路径覆盖：选最少的点边不相交路径，覆盖所有点，特别的，每个点自己可以自环覆盖自己

DAG 最小可相交路径覆盖：选最小的点可相交边不交路径，覆盖所有点



二分图中

1. 最小点覆盖=最大匹配

2. 最小边覆盖=点数-最大匹配

	最差情况每个点都需要一条边覆盖，匹配一次两个点就可以用同一条边覆盖

3. 最大独立集=点数-最小点覆盖=点数-最大匹配

	最小点覆盖摧毁所有边，剩下的都没有边相连

4. 最大独立集=补图最大团

5. 最小不相交路径覆盖=原图点数-拆点后最大匹配

	拆点后每个点匹配一次就可以让两个点的自环变成一条边，减少了一次覆盖

6. 最小可相交路径覆盖，对有向图进行传递闭包，重新建图，转化为不相交路径覆盖

最大流：最大匹配，多重匹配

最小割：最小点权覆盖集，最大点权独立集 对偶问题：最大点权独立集=所有点点权和-最小点覆盖集

费用流：最大带权匹配

**$s$ 和 $A$ 连边，$B$ 和 $t$ 连边**

比较难的就是最小割，抓住割掉边等价于选点

两个点必选一个，转成最小割，点间无穷边，点源汇建连点权

[CF1721F Matching Reduction](https://www.luogu.com.cn/problem/CF1721F)

$I+M=V$

我们知道每删去一个点，最大匹配至多减少 $1$，我们希望构造出这个下界

由于最大独立集 $I$ 中的点不会影响最大匹配，我们直接删掉 $M$ 中任意一个点即可

这样做为什么是正确的呢? 

还是根据 $I+M=V$ 这条性质，我们担心的就是删掉一个节点后最大匹配没变

反证它，设删掉的点为 $u$，形成的匹配为 $(u,v)$，那么只可能是 $v$ 和其它点形成了新匹配 $(v,w)$，但是根据上文 Konig 的证明过程，每条边都是只有一个点在 $M$ 中的，也就是说 $v,w\in I$ 或者 $v\in I,w \in M$，这两种情况都不可能形成 $(v,w)$

我们利用构造定理，删掉最小点覆盖中的点使最小点覆盖 $-1$，这样最大匹配也 $-1$，因为我们直接取这个最小覆盖就能造出一个最大匹配

byd 的不开 `long long` 调了快 $1$ 个小时

```cpp
const int N=4e5+10,M=2e6+10;
int n1,n2,m,k,s=N-1,t=N-2,u,v,ans,inf=2e9;
int h[N],e[M],ne[M],c[M],id[M],idx;
int q[M],d[N],cur[N],vis[N],in[N],mark[N];
vector<int> V;
unordered_set<int> E;

void add(int a,int b,int w,int num)
{
	e[idx]=b,ne[idx]=h[a],c[idx]=w,id[h[a]=idx++]=num;
	e[idx]=a,ne[idx]=h[b],c[idx]=0,id[h[b]=idx++]=num;
}

void dfs(int x)
{
	if(vis[x]) return;
	vis[x]=1;
	for(int i=h[x];~i;i=ne[i])
		if(c[i]) dfs(e[i]); 
}

signed main()
{
	memset(h,-1,sizeof h);
	n1=fr(),n2=fr(),m=fr(),k=fr();
	for(int i=1;i<=n1;i++) add(s,i,1,0);
	for(int i=n1+1;i<=n1+n2;i++) add(i,t,1,0);
	for(int i=1;i<=m;i++)
	{
		u=fr(),v=fr();
		add(u,n1+v,inf,i);
	}
	
	dinic();
	dfs(s);
	for(int i=1;i<=n1;i++) if(!vis[i]) V.pb(i),in[i]=1; //A n T
	for(int i=n1+1;i<=n1+n2;i++) if(vis[i]) V.pb(i),in[i]=1; //B n S
	for(int i=0;i<=idx;i+=2)
	{
		u=e[i^1],v=e[i];
		if(u<=n1 && v>n1 && v<=n1+n2 && c[i]==inf-1)
		{
			mark[u]=mark[v]=id[i];
			E.insert(id[i]),ans+=id[i];
		}
	}
	
	while(k--)
	{
		int op=fr();
		if(op&1)
		{
			int x=V.back();
			V.pop_back();
			ans-=mark[x],E.erase(mark[x]);
			puts("1");
			fw((x<=n1)?x:-(x-n1)),nl;
			fw(ans),nl;
		}
		else
		{
			fw(E.size()),nl;
			for(auto x:E) fw(x),pt;
			nl;
		}
		fflush(stdout);
	}
	return 0;
}
```



[P2423 [HEOI2012\] 朋友圈](https://www.luogu.com.cn/problem/P2423)

很有趣的题目

等价于求 $G=(V=A \cup B,E=E_a \cup E_b)$ 这个图的最大团

$A$ 的条件等价于奇偶连边，$B$ 的条件 $1$ 等价于同奇偶连边，条件二则是不管奇偶的

我们进一步抽象一下这个模型，等价于 $A$ 是奇偶二分图，$B$ 的奇偶集合内部完全图，奇偶之间有边相连

由于二分图中最大团=补图最大独立集=点数-最小点覆盖=点数-最大匹配，而 $B$ 的补图就是二分图，我们可以直接求出 $B$ 的最大团

考虑 $A$ 的影响，我们知道一个二分图的最大团 $\leq 2$，而 $|A|$ 很小，直接枚举 $A$ 的最大团即可

比如 $A$ 选 $1$ 个就是把所有和选择点相连的 $B$ 中点求最大团+1，注意 $B$ 的点子集构成的子图的补图也是二分图

$A$ 选 $2$ 个同理

$O(|A|^2\sqrt {|B|}|B|^2)=O(\text{能过})$ ，每次清空的时候实现要精细一点，dinic `memset` 用循环代替 

```cpp 
const int N=3100,M=(3000*3000/4+6000)*2,K=3e3+10;
int A,B,n,m,s=N-1,t=N-2,inf=2e9;
int h[N],e[M],ne[M],c[M],idx;
int q[M],d[N],cur[N];
int a[K],b[K],in[K],ct[K];
vector<pi> lnk;
vector<int> as[N],now;
int count(int x,int res=0){while(x) x-=x&(-x),res++;return res;}

void solve()
{
	A=fr(),B=fr(),m=fr();
	for(int i=1;i<=A;i++) a[i]=fr(),as[i].clear();
	for(int i=1;i<=B;i++) b[i]=fr();
	for(int i=1,x,y;i<=m;i++) x=fr(),y=fr(),as[x].pb(y);
	
	lnk.clear(),now.clear();
	for(int i=1;i<=B;i++)
		for(int j=1;j<=B;j++)
			if(b[i]&1 && !(b[j]&1) && !(count(b[i]|b[j])&1)) lnk.pb({i,j});
	
	#define u k.first
	#define v k.second
	
	//A 0
	int ans=0;
	memset(h,-1,sizeof h);
	for(pi &k:lnk) add(u,v,1);
	for(int i=1;i<=B;i++)
	{
		b[i]&1?add(s,i,1):add(i,t,1);
		now.pb(i);
	}
	n=B,ans=n-dinic();
	for(int i=1;i<=B;i++) h[i]=-1;
	h[s]=h[t]=-1,idx=0;
	
	//A 1
	for(int i=1;i<=A;i++)
	{
		if((int)as[i].size()<ans) continue;
		now.clear();
		for(int &j:as[i])
		{
			in[j]=1,now.pb(j);
			b[j]&1?add(s,j,1):add(j,t,1);
		}
		
		for(pi &k:lnk)
			if(in[u] && in[v]) add(u,v,1);
		ans=max(ans,(int)as[i].size()-dinic()+1);
		for(int &j:as[i]) in[j]=0,h[j]=-1;
		h[s]=h[t]=-1,idx=0;
	}
	
	//A 2
	for(int i=1;i<=A;i++)
		for(int j=1;j<=A;j++)
			if(a[i]&1 && !(a[j]&1))
			{
				now.clear();
				memset(ct,0,(B+1)*sizeof ct[0]);
				if((int)as[i].size()+(int)as[j].size()+2<=ans) continue;
				for(int &x:as[i]) ct[x]++;
				for(int &x:as[j]) ct[x]++;
				int cnt=0;
				for(int x=1;x<=B;x++)
					if(ct[x]==2) cnt++;
				if(cnt+2<=ans) continue;
				
				for(int x=1;x<=B;x++)
					if(ct[x]==2)
					{
						now.pb(x),in[x]=1;
						b[x]&1?add(s,x,1):add(x,t,1);
					}
				for(pi &k:lnk)
					if(in[u] && in[v]) add(u,v,1);
				ans=max(ans,(int)now.size()-dinic()+2);
				for(int &x:now) h[x]=-1,in[x]=0;
				h[s]=h[t]=-1,idx=0;
			}
	
	#undef u
	#undef v
	fw(ans),nl;
}

int main()
{
	int T=fr();
	while(T--) solve();

	return 0;
}
```



[CF1009G Allowed Letters](https://www.luogu.com.cn/problem/CF1009G) $\text{Hall}$  定理

暴力建图，新建字符节点，每个节点向可以选择的字符连边，从前往后贪心放尽量小的字符，看能不能完美匹配即可

这个复杂度逆天，我们考虑到右侧集合大小很小，只有 $6$，我们用 $Hall$ 定理，枚举右边子集，直接判断是否存在二分图多重完美匹配

需要预处理一堆东西，$O(|S||\Sigma|2^{|\Sigma|})$

```cpp
const int N=1e5+10,U=63;
int n,m;
int f[N],L[U+10],R[U+10][N],ct[N],sz[N];
char s[N],t[N],ans[N];

void upd(int c,int x)
{
	ct[c]+=x;
	for(int S=0;S<=U;S++)
		if((S>>c)&1) L[S]+=x;
}

bool ck(int pos,int c)
{
	if(!ct[c]) return 0;
	upd(c,-1);
	for(int S=0;S<=U;S++)
	{
		if(sz[S]>n-pos) continue;
		if(L[S]>R[S][pos+1]) return upd(c,1),0;
	}
	return 1;
}

int main()
{
	scanf("%s",s+1);
	n=strlen(s+1);
	for(int i=1;s[i];i++) ct[s[i]-'a']++;
	for(int S=0;S<=U;S++)
		for(int i=0;i<=5;i++)
			if((S>>i)&1) L[S]+=ct[i];
	
	m=fr();
	while(m--)
	{
		int pos=fr();
		scanf("%s",t+1);
		for(int i=1;t[i];i++)
			f[pos]|=(1<<t[i]-'a');
	}
	
	for(int S=1;S<=U;S++) sz[S]=sz[S>>1]+(S&1);
	for(int i=1;i<=n;i++)
	{
		if(!f[i]) f[i]=U;
		for(int j=0;j<=5;j++)
			if((f[i]>>j)&1)
				for(int S=0;S<=U;S++)
					if((S>>j)&1) R[S][i]=1;
	}
	for(int S=0;S<=U;S++)
		for(int i=n;i;i--)
			R[S][i]+=R[S][i+1];
	
	for(int i=1;i<=n;i++)
	{
		bool fl=0;
		for(int j=0;j<=5;j++)
			if((f[i]>>j)&1 && ck(i,j)) {ans[i]=j+'a',fl=1;break;}
		if(!fl) return puts("Impossible"),0;
	}
	printf("%s",ans+1);	
	return 0;
}
```



[P3974 [TJOI2015\] 组合数学](https://www.luogu.com.cn/problem/P3974) $\text{Dilworth}$ 定理

网格图构成了一个 `DAG`，考虑拆点，将 $(i, j)$ 拆做 $a_{i, j}$ 个，这 $a_{i, j}$ 个点互不连边，而 $a_{i, j}$ 和 $(i-1, j)$ 产生的 $a_{i-1, j}$ 以及 $(i, j-1)$ 产生的 $a_{i, j-1}$ 个点连 $a_{i, j} \times a_{i-1, j}+a_{i, j} \times a_{i, j-1}$ 条边。

此时问题就等价于求新图的最小链覆盖，由 Dilworth 定理这个东西容易转化成最大独立集。

对于每个点，它右上角和左下角的矩形中的点都是两两无法到达的，我们就是要找到一条路径，选的点从右上到左下，使点权的和最大，因为拆出来的点是完全等价的，如果任意一个点在最大独立集，剩下的也全部在

```cpp
void solve()
{
	n=fr(),m=fr();
	for(int i=1;i<=n;i++)
		for(int j=1;j<=m;j++)
			a[i][j]=fr();
	
	for(int i=1;i<=n;i++)
		for(int j=m;j;j--)
			f[i][j]=max({f[i-1][j+1]+a[i][j],f[i-1][j],f[i][j+1]}); //上一个点向下走向左走
	fw(f[n][1]),nl;
}
```



[P3679 [CERC2016\] 二分毯 Bipartite Blanket](https://www.luogu.com.cn/problem/P3679) 广义 $\text{Hall}$​ 定理

两边点集显然要分开枚举，然后拼起来算答案，这部分比较简单

我们考虑广义 $\text{Hall}$ 定理，只需要判定一个子集是否合法即可，$O(3^n)$，考虑用高维前缀和 $O(n2^n)$

```cpp
const int N=22,M=(1<<20)+10,U=(1<<20)-1;
int n,m,ans;
int F[N],G[N],sz[M],wa[N],wb[N],f[M],vf[M],g[M],vg[M];
char s[N];
vector<int> A,B;

void solve(int n,int *f,int *vf,int *wa,int *F)
{
	for(int S=0;S<=(1<<n)-1;S++)
	{
		for(int i=0;i<n;i++)
			if((S>>i)&1) f[S]|=F[i],vf[S]+=wa[i];
		f[S]=(sz[f[S]]>=sz[S]);
	}
	
	for(int i=0;i<n;i++)
		for(int S=0;S<=(1<<n)-1;S++)
			if((S>>i)&1) f[S]&=f[S^(1<<i)];
}

signed main()
{
	n=fr(),m=fr();
	for(int i=1;i<=n;i++)
	{
		scanf("%s",s+1);
		for(int j=1;j<=m;j++)
			if(s[j]=='1') F[i-1]|=1<<j-1,G[j-1]|=1<<i-1;
	}
	for(int i=1;i<=n;i++) wa[i-1]=fr();
	for(int i=1;i<=m;i++) wb[i-1]=fr();
	
	for(int S=1;S<=U;S++) sz[S]=sz[S>>1]+(S&1);
	solve(n,f,vf,wa,F),solve(m,g,vg,wb,G);
	for(int S=0;S<=(1<<n)-1;S++) if(f[S]) A.pb(vf[S]);
	for(int S=0;S<=(1<<m)-1;S++) if(g[S]) B.pb(vg[S]);
	sort(B.begin(),B.end());
	
	int lim=fr();
	for(int &now:A)
	{
		auto it=lower_bound(B.begin(),B.end(),lim-now);
		ans+=B.end()-it;
	}
	fw(ans);
	return 0;
}
```



[P4298 [CTSC2008\] 祭祀](https://www.luogu.com.cn/problem/P4298) 神题！

第一问求 `DAG` 的最大反链大小，转化成最小可重路径覆盖

跑 `floyd` 然后二分图最大匹配即可

第二问我们设一个集合 $A=\{x|x\in I,x'\in M\}$，即入点和出点不同时在 $I$ 中的，在 $I$ 中的点，则第二问的方案就是 $I-A$ 中所有的出点

证明一下，首先 $|A|=M$，$|I-A|=2n-|M|-|M|=2(n-|M|)$ ，这些点又是最大独立集，原图恰好有 $|I'|=n-|M|$

第三问

这种问是否可行的就直接删掉这个点看行不行

![img](https://cdn.jsdelivr.net/gh/xyzfrozen/Cdn/img/202402172244513.png)

删除所有可以到这个点和这个点可以到的点的点集，如果最小链覆盖只减少一就可行

很难想象 $08$ 年就有这样的题

```cpp
const int N=210,M=4e4+10;
int n,m,u,v,s=N-1,t=N-2,ans,inf=2e9;
int h[N],e[M],ne[M],c[M],idx;
int q[M],cur[N],d[N];
int G[N][N],I[N],ban[N];

int main()
{
	memset(h,-1,sizeof h);
	n=fr(),m=fr();
	while(m--) u=fr(),v=fr(),G[u][v]=1;
	for(int k=1;k<=n;k++)
		for(int i=1;i<=n;i++)
			for(int j=1;j<=n;j++)
				G[i][j]|=G[i][k]&G[k][j];
	for(int i=1;i<=n;i++) add(s,i,1),add(i+n,t,1);
	for(int i=1;i<=n;i++)
		for(int j=1;j<=n;j++)
			if(G[i][j]) add(i,j+n,inf);
	fw(ans=n-dinic()),nl;
	//M=S=(A n T) U (B n S)
	for(int i=1;i<=n;i++) if(~d[i]) I[i]=1;
	for(int i=n+1;i<=(n<<1);i++) if(!~d[i]) I[i]=1;
	for(int i=1;i<=n;i++) fw(I[i]&I[i+n]);
	nl;
	
	for(int x=1;x<=n;x++)
	{
		memset(h,-1,sizeof h),idx=0;
		memset(ban,0,sizeof ban),ban[x]=1;
		for(int i=1;i<=n;i++) ban[i]|=G[x][i]|G[i][x];
		for(int i=1;i<=n;i++)
			for(int j=1;j<=n;j++)
				if(!(ban[i]|ban[j]) && G[i][j]) add(i,j+n,inf);
		int ct=0;
		for(int i=1;i<=n;i++) if(!ban[i]) ct++,add(s,i,1),add(i+n,t,1);
		fw((ct-dinic())==ans-1);
	}
	return 0;
}
```

[CF818G Four Melodies](https://www.luogu.com.cn/problem/CF818G)

非常神秘的题目，暴力建图显然

优化建图从同余下手，$\bmod 7$ 分出来 $7$ 个等价类，每个等价类内部是链，我们考虑给每个节点新建一个同余节点，然后向后面第一个同余的同余节点建边，每个等价类内部都形成了一个通道

每个同余节点向入点连边，下通道，出点向后面第一个同余节点连边，上通道，同时两个同余节点也要连边，这代表当前可以不下通道接着走，把这个点让给别的子序列

对于相差为 $1$ 的情况，我们也同样可以建一个差点通道，抓住在差 $1$ 的情况下等价这个条件，对后面第一个合法节点建立差通道，从出点上，差节点向入点连边，下通道，注意这里我们不把两个差节点建边，因为不能传递

```cpp
const int N=3e3*10+100,M=2e7;
int n,m,s=N-1,t=N-2,ans,res,inf=2e9;
int h[N],e[M],ne[M],c[M],ep[M],idx;
int q[M],vis[N],d[N],cur[N],a[N];

int main()
{
	memset(h,-1,sizeof h);
	n=fr();
	for(int i=1;i<=n;i++) a[i]=fr();
	
	//i 入点 i+n 出点 i+2*n 同余点 i+3*n 差点
	for(int i=1;i<=n;i++)
	{
		for(int j=i+1;j<=n;j++) //从出点上同余通道
			if((a[i]%7)==(a[j]%7)) {add(i+n,j+2*n,inf,0),add(i+2*n,j+2*n,inf,0);break;}
		for(int j=i+1;j<=n;j++) //从出点上差通道
			if(a[i]==a[j]+1) {add(i+n,j+3*n,inf,0);break;}
		for(int j=i+1;j<=n;j++) //从出点上差通道
			if(a[i]==a[j]-1) {add(i+n,j+3*n,inf,0);break;}
	}
		
	for(int i=1;i<=n;i++)
	{
		add(s,i,inf,0),add(i+n,t-1,inf,0),add(i,i+n,1,-1);
		add(i+2*n,i,inf,0),add(i+3*n,i,inf,0);//下通道
	}
	add(t-1,t,4,0);
	dinic(),fw(-res);
	return 0;
}
```

[P7730 [JDWOI-1\] 蜀道难](https://www.luogu.com.cn/problem/P7730)

不难发现等价于差分数组 $b_i \geq 0$

两种属性，正负相关，直接考虑二分图建图

$(s,i,b_i)[b_i \gt 0]$，$(i,t,-b_i)[b_i \leq 0]$

然后操作就是某处 $+1$，某处 $-1$，相当于流量流过去，对两个点连边，跑费用流，最后判断所有和 $t$ 连的边都满流即可

注意这样建边会碰到 $n+1$，我们认为 $n+1$ 可以随便给别的地方 $+1$，就是可以给别的地方流量，连 $(s,n+1,+ \infty)$ 即可



**切糕模型**

每个点有取值 $[1,m]$，有限制形如 $x_{u_i} \leq x_{v_i} +w$

考虑最小割，对每个整数变量拆 $m$ 个点 $p_{i, 1}, p_{i, 2}, \ldots, p_{i,m}$ ，连 $n$ 条链 $S \rightarrow p_{i, 1} \rightarrow p_{i, 2} \rightarrow \cdots \rightarrow p_{i, m} \rightarrow p_{i, m+1} \rightarrow T$ ， $p_{i, m+1} \rightarrow T$ 的容量为 $\infty$ (表示不能割这条边)， $p_{i, j} \rightarrow p_{i, j+1}$ 的容量为 $a_{i, j+1}$ 。然后 $p_{v_i, j+w_i} \rightarrow p_{u_i, j}$ ，容量为 $\infty$ ，表示强制让 $S$ 和 $p_{v i, j+w i}$ 与 $p_{u i, j}$ 和 $T$ 的连通关系不同。如果选了不合法的方案，那么 $S \rightarrow T$ 还能经过这条边，不是最小割了

这个建图的本质就是让所选割边强制在同一侧，这样就是合法最小割

[P5295 [北京省选集训2019\] 图的难题](https://www.luogu.com.cn/problem/P5295)

图合法当且仅当任意导出子图满足 $|E| \leq 2|V|-2$

可以认为是拆成两颗生成树，然后黑白染色

导出子图 $(V,E)$ 一一对应，连边 $((u,v),u,+\infty),((u,v),v,+\infty)$ 最大权闭合子图即可

注意到这样做答案最优是空集，我们可以强选一个点，然后把这个点的点权变成 $0$ 即可

枚举每个点的复杂度是 $O(Tn\sqrt n m)$ 的，注意到每次只会改变一条边，流量很少，可以用退流技巧

去掉边 $(u,v)$ 等价于跑 $f(u,s) \cup f(t,v)$，然后 $(u,v)$ 正反变流量清空

```cpp
const int N=2e3+10,M=510*14*4;
int n,m,u,v,s=N-1,t=N-2,ans,inf=2e9;
int h[N],e[M],ne[M],c[M],idx;
int q[M],cur[N],d[N];
struct Edge{int u,v;}E[M];

int work()
{
	//|E|-2|V|
	memset(h,-1,sizeof h),idx=0;
	for(int i=1;i<=n;i++) add(i,t,2);
	for(int i=1;i<=m;i++)
	{
		u=E[i].u,v=E[i].v;
		add(s,i+n,1),add(i+n,u,inf),add(i+n,v,inf);
	}
	return m-2-dinic();
}

void solve()
{
	n=fr(),m=fr();
	for(int i=1;i<=m;i++) E[i]={fr(),fr()};
	work();
	
	int flow=0;
	for(int i=h[s];~i;i=ne[i]) flow+=c[i^1];
	for(int i=0,x=1;i<=(n<<1)-1;i+=2,x++)
	{
		//del(x,t)->f(x,s)+f(t,t)
		s=x,t=N-1;
		flow-=dinic(),c[i]=c[i^1]=0;
		s=N-1,t=N-2;
		flow+=dinic();
		if(m-2-flow>-2) return void(puts("No"));
		c[i]=2;
	}
	return void(puts("Yes"));
}
```
