# 线性基

## Intro

[线性基学习笔记 | Menci's OI Blog](https://oi.men.ci/linear-basis-notes/)

张成/线性空间：任意子集异或得到的数构成的集合

元素表示：元素异或

线性相关：某个元素可以被其它集合内元素表示出来

线性无关：任意元素都不不能被其它元素表示出来

线性基 $B$：可以表示出原集合 $S$，且线性无关

性质：线性基是满足性质的最小集合，大小 $|B|\leq \log \max S_i$

## 算法流程

可以在 $O(n\log V)$ 的时间构造，合并两个线性基集合 $O(\log^2 V)$

在线算法，增量构造，不显示时支持动态插入，$O(\log V)$，空间也是 $O(\log V)$，所以也有线段树维护线性基

1. 从最高位开始枚举当前插入的数 $x$

2. 如果当前为 $x_j=1$

3. 如果 $ a_ {j} $ $ \neq $ 0，则令 $x \to x\oplus a_j$ 

4. 如果 $a_{j}=0$，则

	$\forall k \in [0,j-1]$，如果 $x$ 的第 $k$ 位为 $1$，$x\to x\oplus a_{k}$ 

	$\forall k \in [j+1,\log V]$，如果 $a_k$ 第 $j$ 为 $1$，$a_k \to a_k \oplus x$

5. 插入 $x$，$a_j=x$

$B$ 就是所有数插入完了之后，所有 $a_i \neq 0$ 的 $a_i$ 构成的集合

性质：

对于每一个 $i$，$a_i$ 有以下两种可能：

1. $a_i=0$，只有满足 $j>i$ 的 $a_j$ (即，位于 $a_i$ 后面的所有 $a_j$ ) 的第 $i$ 个二进制位可能为 $1$

2. $a_i \neq 0$

  整个 $a$ 数组中只有 $a_i$ 的第 $i$ 个二进制位为 $1$

  $a_i$ 更高的二进制位 ( $j>i$ 的二进制位) 一定为 $0$

  $a_i$ 更低的二进制位 ( $j<i$ 的二进制位) 可能为 $1$，为 $1$ 当且仅当 $a_j=0$

$B$ 的子集异或不可能为 $0$，否则不是线性无关的

相当于一个模为 $\log V$ 的向量，向量的每一个维度控制一位，这就是这个构造最强的性质



## Problem

[模板题](https://www.luogu.com.cn/problem/P3812)

求最大子集异或和，等价于 $B$ 的全部元素异或和

首先 $B$ 可以表示出 $S$ 的每一个元素，当然可以表示出子集的异或和

如果 $a_i \neq 0$，直接加入 $a_i$ 即可，因为相当于加上了 $2^i$ 减去了一些数，和 $\lt 2^i$，肯定更优

```cpp
#include<bits/stdc++.h>
#define int long long
#define pt putchar(' ')
#define nl puts("")
#define pi pair<int,int>
#define pb push_back
#define go(it) for(auto &it:as[x])
using namespace std;

const int N=55;
int n,ans;
int a[N];

void ins(int x)
{
	for(int i=50;~i;i--)
	{
		if(!x) return;
		if(!((x>>i)&1)) continue;
		if(a[i]) x^=a[i];
		else
		{
			for(int k=0;k<=i-1;k++) if(a[k] && (x>>k)&1) x^=a[k];
			for(int k=i+1;k<=50;k++) if(a[k] && (a[k]>>i)&1) a[k]^=x;
			return void(a[i]=x);
		}
	}
}

signed main()
{
	n=fr();
	for(int i=1;i<=n;i++) ins(fr());
	for(int i=0;i<=50;i++) ans^=a[i];
	fw(ans);
	return 0;
}
```



[HDU 3949](http://acm.hdu.edu.cn/showproblem.php?pid=3949)

$k$ 小子集异或和

首先如果 $|B| \lt n$ 说明至少有一个数可以被表示出来存在异或子集为 $0$，先把 `k--`

本质不同的非 $0$ 异或子集只有 $2^{|B|}-1$ 种，先判掉无解

把 $B$ 集合构造出来，此时的 $a_i$ 代表第 $i$ 个元素

对 $k$ 放在 $[0,|B|)$ 轴上做二进制拆分，遍历每一位，如果第 $i$ 位为 $1$，则 $\oplus\,a_i$ 

因为选高位就可以更大，而因为每一位的 $1$ 至多被一个 $B$ 中的数获得，选高位不会影响低位

比它小的异或子集肯定是不选某些高位的 $1$，那么剩下的就可以随便选了，每一个二进制数唯一对应一个方案数

[P4151 [WC2011\] 最大XOR和路径](https://www.luogu.com.cn/problem/P4151)

首先我们先搜出来一个 `dfs` 树，本质上一个无向图就是一个 `dfs` 树挂了一些返祖边

我们已经跑出树上 $1 \to n$ 的路径作为最初的答案，然后考虑增大它，就是跑一些环的答案

跑一些环我们可以从 $1$ 跑到环上绕一圈得到环的权值然后再原路返回，这样相当于只有环的答案，然后最后再跑树上 $1$ 到 $n$ 的路径

任意一个环都可以由简单环异或得来，只用考虑简单环，就是树边+一条返祖边

问题等价于，给你一些数，和一个目标值 $x$，选出一个子集 $\oplus x$ 最大，考虑用线性基完成

首先插入所有基本环构建 $B$，然后从高位向低位跑就行了

```cpp
const int N=5e4+10;
int n,m,u,v,w,stm;
int dfn[N],len[N],a[N];
vector<pi> as[N];
vector<int> B;

void dfs(int x)
{
	dfn[x]=++stm;
	for(auto &[v,w]:as[x])
		if(!dfn[v]) len[v]=len[x]^w,dfs(v);
}

void ins(int x)
{
	for(int i=62;~i;i--)
	{
		if(!x) return;
		if(!((x>>i)&1)) continue;
		if(a[i]) x^=a[i];
		else
		{
			for(int k=0;k<=i-1;k++) if(a[k] && (x>>k)&1) x^=a[k];
			for(int k=i+1;k<=62;k++) if(a[k] && (a[k]>>i)&1) a[k]^=x;
			return void(a[i]=x);
		}
	}
}

signed main()
{
	n=fr(),m=fr();
	for(int i=1;i<=m;i++)
	{
		u=fr(),v=fr(),w=fr();
		as[u].pb({v,w}),as[v].pb({u,w});
	}
	
	dfs(1);
	for(int x=1;x<=n;x++)
		for(auto &[v,w]:as[x])
			if(dfn[v]<dfn[x]) ins(len[x]^len[v]^w);
	for(int i=62;~i;i--)
		if(a[i] && (len[n]^a[i])>len[n]) len[n]^=a[i];
	fw(len[n]);
	return 0;
}
```



[P4869 albus就是要第一个出场](https://www.luogu.com.cn/problem/P4869)

首先还是做线性基

现在证明一个结论，对于线性基 $B$ 的任意一个子集 $B'$，$\bigoplus B'= \bigoplus S'$ 出现的次数为 $2^{n-|B|}$

令 $A=S-B$

$A' \oplus B'$ 构造出异或值为 $0$ 的方案数是 $2^{|A|}-1$，设某一种方案为 $Z$

若 $B' \cap Z=\varnothing$， $B'\cup Z$ 表出的值与 $B'$ 表出的值相等
若 $B' \subseteq Z$ ， $\complement_Z B'$ 表出的值与 $B'$ 表出的值相等
若 $B' \cap Z \neq \varnothing$ 且 $B' \not \subseteq Z$ ，则将 $B'$ 分为两个集合 $P=\{x \mid x \in B', x \notin Z\}$ 和 $Q=B' \cap Z$ ，则集合 $P \cup\left(\complement_Z Q\right)$ 表出的值与 $B'$ 表出的值相等

于是对于任意 $B$ 和 $Z$ ，我们都可以构造一个不同的集合 $S$ 使其表出的值与 $B$ 表出的值相等，又因为任意 $B$ 表出的值不同，所以所有 $2^n$ 个子集共能表出 $2^k$ 个不同的值，其中每个值 $2^{n-k}$ 个

问题变为求有多少个 $B'$ 异或值小于当前数

把 $B$ 集合构造出来，此时的 $a_i$ 代表第 $i$ 个元素

然后如果 $k$ 的第 $pos_i$ 位为 $1$，则必选 $a_i$ 这元素，$pos_i$ 表示 $a_i$ 原来是 $[0,\log V)$ 中的哪一位

当前这个 $1$ 必选，剩下的随便选，我们发现这样空集没有统计，但是自己统计了，答案还是没变的

```cpp
#include<bits/stdc++.h>
#define pt putchar(' ')
#define nl puts("")
#define pi pair<int,int>
#define pb push_back
#define go(it) for(auto &it:as[x])
using namespace std;

const int N=35,Q=10086;
int n;
int a[N];

void ins(int x)
{
	for(int i=30;~i;i--)
	{
		if(!x) return;
		if(!((x>>i)&1)) continue;
		if(a[i]) x^=a[i];
		else
		{
			for(int k=0;k<=i-1;k++) if(a[k] && (x>>k)&1) x^=a[k];
			for(int k=i+1;k<=30;k++) if(a[k] && (a[k]>>i)&1) a[k]^=x;
			return void(a[i]=x);
		}
	}
}

int rk(int x)
{
	int ans=0,cnt=0;
	for(int i=0;i<=30;i++)
		if(a[i]) ans+=((x>>i)&1)*(1<<cnt),cnt++; //选这一位，剩下的 1 有 2^(cnt-1) 随便选的方案
	ans%=Q;
	for(int i=cnt+1;i<=n;i++)
		(ans<<=1)%=Q;
	return (ans+1)%Q;
}

int main()
{
	n=fr();
	for(int i=1;i<=n;i++) ins(fr());
	fw(rk(fr()));

	return 0;
}
```
