## 整除分块

### Intro

$O(\sqrt n)$，用于处理关于 $\lfloor \frac xi\rfloor$ 相关的式子，其中 $x$ 是定值

核心就是 $\lfloor \frac xl \rfloor=\lfloor \frac x{\lfloor \frac xl \rfloor}\rfloor$ 这个玩意只有 $O(\sqrt n)$ 个

对于 $d \leq \sqrt n$ ，$\lfloor \frac xd\rfloor$ 只有 $\sqrt n$ 个

对于 $d \gt \sqrt n$，$\lfloor \frac xd\rfloor \leq \sqrt n$ 只有 $\sqrt n$ 个

性质
$$
\forall a, b, c \in \mathbb{Z},\left\lfloor\frac{a}{b c}\right\rfloor=\left\lfloor\frac{\left\lfloor\frac{a}{b}\right\rfloor}{c}\right\rfloor
$$

证明:
$$
\begin{aligned}
& \frac{a}{b}=\left\lfloor\frac{a}{b}\right\rfloor+r(0 \leq r<1) \\
\Longrightarrow & \left\lfloor\frac{a}{b c}\right\rfloor=\left\lfloor\frac{a}{b} \cdot \frac{1}{c}\right\rfloor=\left\lfloor\frac{1}{c}\left(\left\lfloor\frac{a}{b}\right\rfloor+r\right)\right\rfloor=\left\lfloor\frac{\left\lfloor\frac{a}{b}\right\rfloor}{c}+\frac{r}{c}\right\rfloor=\left\lfloor\frac{\left\lfloor\frac{a}{b}\right\rfloor}{c}\right\rfloor
\end{aligned}
$$
多维整除分块取 $\min$ 即可，$O(k\sqrt n)$，$k$ 为维数

### Problem

[Floor and Mod](https://www.luogu.com.cn/problem/CF1485C)

可以轻松推出 $a=k(b+1)$ 我们考虑枚举 $i=b+1$
$$
ans=\sum_{i=2}^{y+1} \lfloor \frac {\min(x,i^2-i-1)}{i} \rfloor
$$
$\min(x,i^2-i-1)$ 是因为 $0\leq k \lt b \Rightarrow a \lt b(b+1) \Rightarrow a \leq i^2-i-1$

取 $i^2-i-1$ 的时候是 $i-1$ 是个等差数列，后面是整除分块，考虑到 $i^2-i-1 \leq x$ 只有 $\sqrt n$ 个，直接暴力算前面即可

$O(T\sqrt n)$

```cpp
void solve()
{
	x=fr(),y=fr();
	int bdry=2,ans=0;
	while(1)
	{
		if(bdry*bdry-bdry-1>x || bdry>y+1) break;
		ans+=(bdry*bdry-bdry-1)/bdry;
		bdry++;
	}
	bdry--;
	//for(int i=bdry+1;i<=y+1;i++) ans+=x/i;
	for(int l=bdry+1,r;l<=y+1;l=r+1)
	{
		if(x<l) break;
		r=min(y+1,x/(x/l));
		ans+=(r-l+1)*(x/l);
	}
	fw(ans),nl;
}
```

## 狄利克雷卷积

简单介绍几个积性函数

$\epsilon(n)=[n=1], I(n)=1, i d(n)=n$

设 $f, g$ 是两个数论函数，它们的狄利克雷卷积卷积是: $(f * g)(n)=\sum_{d \mid n} f(d) g\left(\frac{n}{d}\right)$

性质：满足交换律，结合律

单位元: $\epsilon$ (即 $f * \epsilon=f$ )

结合狄利克雷卷积得到的几个性质：

1. $\mu * I=\epsilon$
2. $\varphi * I=i d$
3. $\mu * i d=\varphi$

$$
\begin{aligned}
& \varepsilon=\mu * 1 \Longleftrightarrow \varepsilon(n)=\sum_{d \mid n} \mu(d) \\
& d=1 * 1 \Longleftrightarrow d(n)=\sum_{d \mid n} 1 \\
& \sigma=\mathrm{id} * 1 \Longleftrightarrow \sigma(n)=\sum_{d \mid n} d \\
& \varphi=\mu * \mathrm{id} \Longleftrightarrow \varphi(n)=\sum_{d \mid n} d \cdot \mu\left(\frac{n}{d}\right)
\end{aligned}
$$

### 狄利克雷前缀和

求 $f_n=\sum_{d \mid n} g_d$

直接枚举倍数的话显然可以做到 $O(n\log n)$

根据唯一分解定理,我们可以设 $i=\prod p_i^{\alpha_i}$，$j=\prod p_i^{\beta_i}$，则 $g_j$ 贡献到 $f_i$ 当且仅当 $\forall i,\alpha_i\geq\beta_i$

发现这个实际上就是一个关于质因子分解后的指数的高维前缀和，即每个数字会被它除以所有质因子的那个数转移过来,所有的质因子构成了一组正交基

## 莫比乌斯

### 莫比乌斯函数

**积性函数**

$f(1)=1$ 

当 $\operatorname{gcd}(\mathrm{a}, \mathrm{b})=1$ 有 $f(a b)=f(a) f(b)$ ，则 $f(n)$ 为积性函数

欧拉函数和莫比乌斯函数都是积性函数

**欧拉函数**
$$
\phi(n)=\sum_{i=1}^n[\operatorname{gcd}(i, n)=1]
$$

性质: $\sum_{d \mid n} \phi(d)=n$

**莫比乌斯函数**
$$
\mu(n)= \begin{cases}1 & n=1 \\ (-1)^s & n=p_1 p_2, \cdots p_s \\ 0 & \text { n包含相同质因子 }\end{cases}
$$

性质：
$$
\sum_{d \mid n} \mu(d)=[n=1]
$$

证明：

令 $n=p_1^{\alpha_1}p_2^{\alpha_2}\ldots p_k^{\alpha_k} \gt 1$

首先去掉所有 $\mu(d)=0$ 的因子，剩下的因子每个 $p_i$ 的 $\alpha_i=[0/1]$

枚举 $1$ 的个数，答案为 $C_{k}^0 (-1)^0+C_{k}^1(-1)^1+\ldots+C_{k}^k(-1)^k$ ，由二项式定理 $(1-1)^k=\sum_{i=0}^k C_{k}^i (-1)^i=0$



欧拉函数性质反演结论
$$
\sum_{d \mid n} \mu(d) \frac{n}{d}=\phi(n)
$$
线性晒求莫比乌斯函数

```cpp
void Mu(int n)
{
	mu[1]=1;
	for(int i=2;i<=n;i++)	
	{
		if(!p[i]) mu[pr[++cnt]=i]=-1;
		for(int j=1;pr[j]<=n/i;j++)
		{
			p[pr[j]*i]=1;
			if(!(i%pr[j])) break; //mu=0
			mu[i*pr[j]]=-mu[i];
		}
	}
	for(int i=1;i<=n;i++) s[i]=mu[i]+s[i-1];
}
```

### 莫比乌斯反演

若 $F(n)=\sum_{d \mid n} f(d)$，则 $f(n)=\sum_{d \mid n} \mu(d)F(\frac nd)$

证明：
$$
\begin{aligned}
\sum_{d\mid n}\mu(d)F(\frac nd)&=\sum_{d \mid n} \mu(d)\sum_{i \mid \frac nd} f(i)\\
&=\sum_{i \mid n} f(i) \sum_{d \mid \frac ni}\mu(d)\\
&=\sum_{i \mid n} f(i)[\frac ni=1]\\
&=f(n)
\end{aligned}
$$
中间的一步求和变换，可以看做是展开后重新求和，$i \mid \frac nd \Rightarrow d\mid \frac ni$

若 $F(n)=\sum_{n \mid d} f(d)$，则 $f(n)=\sum_{n \mid d} \mu (\frac dn)F(d)$
$$
\begin{aligned}
\sum_{n \mid d} \mu (\frac dn)F(d)&=\sum_{n \mid d} \mu (\frac dn)\sum_{d\mid i}f(i)\\
&=\sum_{n \mid i}f(i)\sum_{(d' =\frac dn)\mid \frac in} \mu(d')\\
&=\sum_{n \mid i}f(i)[\frac in=1]\\
&=f(n)
\end{aligned}
$$
令 $d'=\frac dn$，$d \mid i \Rightarrow d'n \mid i \Rightarrow d' \mid \frac in$



### Problem

[P2522 [HAOI2011\] Problem b](https://www.luogu.com.cn/problem/P2522)

设 $F(n)=\sum_{i=1}^a\sum_{j=1}^b [n\mid(i,j)]$，$f(n)=\sum_{i=1}^{a}\sum_{j=1}^b [(i,j)=n]$
$$
F(n)=\sum_{n\mid d}f(d)=\lfloor \frac an\rfloor\lfloor \frac bn\rfloor\\
f(n)=\sum_{n\mid d}\mu(\frac dn) F(d)=\sum_{d'=1} \mu(d')F(d'n)
$$
整除分块即可

$O(T(\sqrt {\min(a,b)}))$

```cpp
const int N=5e4+10;
int a,b,c,d,k,cnt;
int mu[N],s[N],p[N],pr[N];

void Mu(int n)
{
	mu[1]=1;
	for(int i=2;i<=n;i++)	
	{
		if(!p[i]) mu[pr[++cnt]=i]=-1;
		for(int j=1;pr[j]<=n/i;j++)
		{
			p[pr[j]*i]=1;
			if(!(i%pr[j])) break; //mu=0
			mu[i*pr[j]]=-mu[i];
		}
	}
	for(int i=1;i<=n;i++) s[i]=mu[i]+s[i-1];
}

int calc(int a,int b)
{
	a/=k,b/=k;
	if(!a || !b) return 0;
	int ans=0;
	for(int l=1,r;l<=min(a,b);l=r+1)
	{
		r=min(a/(a/l),b/(b/l));
		ans+=(s[r]-s[l-1])*(a/l)*(b/l);
	}
	return ans;
}

void solve()
{
	a=fr(),b=fr(),c=fr(),d=fr(),k=fr();
	fw(calc(b,d)-calc(a-1,d)-calc(b,c-1)+calc(a-1,c-1)),nl;
}

signed main()
{
	Mu(N-10);
	int T=fr();
	while(T--) solve();
	return 0;
}
```



求
$$
\sum_{i=1}^n \sum_{i=1}^m \operatorname{lcm}(i,j)
$$

$$
\begin{aligned}
\text { ans } & =\sum_{i=1}^n \sum_{i=1}^m \operatorname{lcm}(i, j) \\
& =\sum_{i=1}^n \sum_{i=1}^m \frac{i j}{\operatorname{gcd}(i, j)} \\
& =\sum_{d=1}^{\min (n, m)} d \sum_{i=1}^{\left\lfloor\frac{n}{d}\right\rfloor} \sum_{j=1}^{\left\lfloor\frac{m}{d}\right\rfloor} i j[\operatorname{gcd}(i, j)=1]
\end{aligned}
$$

$\frac {ij}{d}=d \times \frac {i}{d} \frac {j}{d}$

$\sum_{d \mid n}\mu(n)=[n=1]$
$$
\text { ans }=\sum_{d=1}^{\min (n, m)} d \sum_{i=1}^{\left\lfloor\frac{n}{d}\right\rfloor} \sum_{j=1}^{\left\lfloor\frac{m}{d}\right\rfloor} \sum_{x \mid \operatorname{gcd}(i, j)} \mu(x) \times i \times j
$$
将 $\sum_{x \mid \gcd(i,j)}\mu(x)$ 提前，考虑 $\gcd(i,j)$ 的对 $x$ 的贡献
$$
\text { ans }=\sum_{d=1}^{\min (n, m)} d \sum_{x=1}^{\min \left(\left\lfloor\frac{n}{d}\right\rfloor,\left\lfloor\frac{m}{d}\right\rfloor\right)} \mu(x) x^2 \sum_{i=1}^{\left\lfloor\frac{n}{d x}\right\rfloor} i \sum_{j=1}^{\left\lfloor\frac{m}{d x}\right\rfloor} j
$$
直接做是 $O(\sum_{i=1}^n \sqrt {\frac ni})=O(n)$ 的

多组询问这个就爆了

再次变换，两项合一 $k=dx$，令 $S(n)=(1+2+\ldots +n)$
$$
ans=\sum_{k=1}^{\min(n,m)} k\,S(\lfloor \frac nk\rfloor)S(\lfloor \frac mk\rfloor) \sum_{d \mid k}\mu(d)d
$$
令 $f(k)=k\sum_{d \mid k}\mu(d)d$，求这个函数的前缀和，不能杜教筛，但是 $\sum_{d \mid k} \mu(d)d$ 是一个积性函数
$$
\begin{aligned}
f(\mathbb{T})& =f(\prod p_i^{\alpha_i})  \\
&=\prod_{i=1}^tf(p_i^{\alpha_i}) \\
  & =\prod_{i=1}^{t}(P_{i}^{0}\times \mu(1)+P_{i}^1 \times \mu(P_{i})+p_{i}^{2}\times\mu(P_{i}^{2})+P_{i}^{3}\times\mu(P_{i}^{3})+\cdots)  \\
& =\prod_{i=1}^{t}(1-1\times p_{i})\quad(\mu(p_{i}^{2})=0)  \\
& =\prod_{i=1}^{t}(1-p_{i})  \\
\end{aligned}
$$
直接线性筛

```cpp
const int N=1e7+10,Q=20101009;
int n,m,cnt,ans;
int p[N],pr[N],f[N],g[N];

void Add(int &x,int y){if((x+=y)) x-=Q;}
int S(int x){return (x*(x+1)/2)%Q;}

void sieve(int n)
{
	f[1]=1;
	for(int i=2;i<=n;i++)
	{
		if(!p[i]) f[i]=(1-i+Q)%Q,pr[++cnt]=i;
		for(int j=1;pr[j]<=n/i;j++)
		{
			int t=pr[j]*i;
			p[t]=1;
			if(!(i%pr[j]))
			{
				f[t]=f[i];
				break;
			}
			f[t]=f[i]*f[pr[j]]%Q;
		}
	}
	for(int i=1;i<=n;i++)
		g[i]=g[i-1],Add(g[i],f[i]*i%Q);
}

signed main()
{
	sieve(N-10);
	n=fr(),m=fr();
	for(int l=1,r;l<=min(n,m);l=r+1)
	{
		r=min({n/(n/l),m/(m/l)});
		Add(ans,(g[r]-g[l-1]+Q)%Q*S(n/l)%Q*S(m/l)%Q);
	}
	while(ans<0) ans+=Q;
	fw(ans);
	return 0;
}
```



[LCMSUM - LCM Sum](https://www.luogu.com.cn/problem/SP5971)
$$
\begin{aligned}
\text{ans}& \mathrm{=\sum_{i=1}^n\mathrm{lcm(i,n)}}  \\
&\mathrm{=\sum_{i=1}^n\frac{i\cdot n}{\gcd(i,n)}} \\
&\mathrm{=n\times\sum_{i=1}^n\frac i{gcd(i,n)}} \\
&\mathrm{=n\times\sum_{d|n}\sum_{i=1}^n\frac{i}{d}\left[gcd(i,n)=d\right]} \\
&\mathrm{=n\times\sum_{d|n}\sum_{i=1}^n\frac{i}{d}\left[\gcd(\frac id,\frac nd)\right]} \\
&\mathrm{=n\times\sum_{d|n}\sum_{i=1}^{\lfloor\frac nd\rfloor}i\cdot[\gcd(i,\frac nd)]}& (\mathrm{i}=\mathrm{id})\\
&\mathrm{=n \times \sum_{d \mid n}\sum_{i=1}^d i [(i,d)=1]}
\end{aligned}
$$
后面那个式子的意义是 $1 \sim n$ 中与 $n$ 互质的数的和

当 $n=1$ 时，$f(n)=1$

当 $n \gt 2$ 时，$f(n)=\frac{\varphi(n)n}2$

因为 $\gcd(n,x)=\gcd(n,n-x)$ 所以成对出现

Dirichlet 前缀和即可

[P2257 YY的GCD](https://www.luogu.com.cn/problem/P2257)
$$
\sum_{p \in \text { prime }} \sum_{d=1}^{\left\lfloor\frac{n}{p}\right\rfloor} \mu(d)\left\lfloor\frac{n}{p d}\right\rfloor\left\lfloor\frac{m}{p d}\right\rfloor
$$

两项合一 $k=pd$
$$
\begin{aligned}
ans&=\sum_{k=1}^n \lfloor \frac nk\rfloor \lfloor \frac mk \rfloor \sum_{d \mid k} \mu(d)[\frac kd \in P]
\end{aligned}
$$
相当于去掉 $k$ 的某个质因子的 $\mu$​ 和，转换一下，设 $f(k)=\sum_{p \mid k}\mu(\frac kp)$


$$
f(t)=
\begin{cases}
\mu(1) &[t\in P]\\
\mu(i) &[i \bmod p_j=0] \\
-f(i)+\mu(i) &[i \bmod p_j]
\end{cases}
$$
$\bmod =0$ 时直接讨论当前这个 $p_j$ 的个数即可

如果 $i$ 中 $p_j$ 只有一个，那么只有 $\mu (\frac t{p_j}=i) \neq 0$，有多个全为 $0$

$\bmod \neq 0$ 时，原来所有含有的 $\mu$ 现在因为多了一个质因子变成相反数，再补上 $\mu(i)$

```cpp
const int N=1e7+10;
int n,m,cnt;
int p[N],pr[N],mu[N],f[N];

void sieve(int n)
{
	mu[1]=1;
	for(int i=2;i<=n;i++)
	{
		if(!p[i]) pr[++cnt]=i,mu[i]=-1,f[i]=1;
		for(int j=1;pr[j]<=n/i;j++)
		{
			int t=pr[j]*i;
			p[t]=1;
			if(!(i%pr[j])) 
			{
				f[t]=mu[i];
				break;
			} //mu[t]=0;
			mu[t]=-mu[i];
			f[t]=-f[i]+mu[i];
		}
	}
	for(int i=1;i<=n;i++) f[i]+=f[i-1];
}

void solve()
{
	n=fr(),m=fr();
	int ans=0;
	for(int l=1,r;l<=min(n,m);l=r+1)
	{
		r=min(n/(n/l),m/(m/l));
		ans+=(f[r]-f[l-1])*(n/l)*(m/l);
	}
	fw(ans),nl;
}
```




[P3327 [SDOI2015\] 约数个数和](https://www.luogu.com.cn/problem/P3327)

$d(ij)=\sum_{x\mid i} \sum_{y \mid j}[(x,y)=1]$
$$
\begin{aligned}
ans&=\sum_{i=1}^n\sum_{j=1}^m\sum_{x \mid i}\sum_{y \mid j}\sum_{d \mid (x,y)} \mu (d)\\
&=\sum_{x=1}^n\sum_{y=1}^m \sum_{d \mid (x,y)}\mu(d) \lfloor \frac nx\rfloor\lfloor \frac my\rfloor\\
&=\sum_{d=1}^{\min (n,m)} \mu(d)\sum_{x=1}^{\lfloor \frac nd\rfloor}\sum_{y=1}^{\lfloor \frac md \rfloor}  \lfloor \frac {\frac nd}{x}\rfloor\lfloor \frac {\frac md}{y}\rfloor
\end{aligned}
$$

```cpp
	}

}
```

## 杜教筛

### Intro

求积性函数的前缀和，$O(n^{\frac 34}/n^{\frac 23})$

设 $h=f\cdot g$
$$
\begin{aligned}
\sum_{i=1}^nh(i)& =\sum_{i=1}^n\sum_{d|i}f(\frac id)g(d)  \\
&=\sum_{d=1}^ng(d)\sum_{i=d}^nf(\frac id)[i|d] \\
&=\sum_{d=1}^ng(d)\sum_{i=1}^{n/d}f(i) \\
&=\sum_{d=1}^ng(d)S(\frac nd) \\
&=g(1)S(n)+\sum_{d=2}^ng(d)S(\frac nd)
\end{aligned}
$$
直接暴力记搜是 $O(n^{\frac 34})$ 的，需要预处理出前 $O(n^{\frac 23})$ 的数，这样是 $O(n^{\frac 23})$ 的

### Problem

求 $\sum_{i=1}^n \mu(i)$

$\mu \cdot I=\epsilon$
$$
1=S(n)+\sum_{i=2}^nS(\lfloor \frac nd \rfloor)
$$
求 $\sum_{i=1}^n \varphi(i)$

$\varphi\,\cdot I=id$
$$
\frac {n(n+1)}2=S(n)+\sum_{d=2}^nS(\lfloor \frac nd \rfloor)
$$
合起来就是 [P4213 【模板】杜教筛](https://www.luogu.com.cn/problem/P4213)

最慢的点跑了 894ms

```cpp
const int N=1e7+10;
int n,cnt;
int mu[N],phi[N],p[N],pr[N];

void sieve(int n)
{
	mu[1]=phi[1]=1;
	for(int i=2;i<=n;i++)
	{
		if(!p[i]) phi[i]=i-1,mu[i]=-1,pr[++cnt]=i;
		for(int j=1;pr[j]<=n/i;j++)
		{
			int t=pr[j]*i;
			p[t]=1;
			if(!(i%pr[j]))
			{
				phi[t]=phi[i]*pr[j],mu[t]=0;
				break;
			}
			phi[t]=phi[i]*(pr[j]-1),mu[t]=-mu[i];
		}
	}
	for(int i=1;i<=n;i++) mu[i]+=mu[i-1],phi[i]+=phi[i-1];
}

int Mu(int n)
{
	if(n<=N-10) return mu[n];
	if(Smu.count(n)) return Smu[n];
	int ans=1;
	for(int l=2,r;l<=n;l=r+1)
	{
		r=n/(n/l);
		ans-=(r-l+1)*Mu(n/l);
	}
	return Smu[n]=ans;
}

int Phi(int n)
{
	if(n<=N-10) return phi[n];
	if(Sphi.count(n)) return Sphi[n];
	int ans=n*(n+1)/2;
	for(int l=2,r;l<=n;l=r+1)
	{
		r=min(n,n/(n/l));
		ans-=(r-l+1)*Phi(n/l);
	}
	return Sphi[n]=ans;
}

	n=fr();
	fw(Phi(n)),pt,fw(Mu(n)),nl;
}
```

求
$$
\sum_{x=1}^n x^3 \sum_{d=1}^{\lfloor \frac nx \rfloor} \mu(d) d^2 \sum_{i=1}^{\lfloor \frac {n}{xd}\rfloor} \sum_{j=1}^{\lfloor \frac {n}{xd}\rfloor} ij
$$


后面两项可以分离再合并相当于 $(1+2+\ldots+\lfloor \frac {n}{xd}\rfloor)^2$

看到两项直接拆，令 $k=xd$
$$
\begin{aligned}
\sum_{x=1}^n x^3 \sum_{d=1}^{\lfloor \frac {n}{x}\rfloor} \mu(d)d^2 S(\lfloor \frac {n}{xd}\rfloor)^2&=\sum_{k=1}^n k^2S(\lfloor \frac {n}{k}\rfloor)^2 \sum_{x \mid k} \mu(\frac kx)x\\
&=\sum_{k=1}^n k^2S(\lfloor \frac {n}{k}\rfloor)^2\varphi(k)
\end{aligned}
$$


上一发杜教筛
$$
\text{set}\,f=\varphi(n)id^2 g=id^2\\
h=f \cdot g=\sum_{d \mid n} \varphi(\frac nd)(\frac nd)^2 d^2=n^2\sum_{d \mid n} \varphi(\frac nd)=n^2\varphi I=n^3\\
\sum_{i=1}^n n^3=S(n)+\sum_{d=2}^n d^2S(\lfloor \frac nd\rfloor)
$$
