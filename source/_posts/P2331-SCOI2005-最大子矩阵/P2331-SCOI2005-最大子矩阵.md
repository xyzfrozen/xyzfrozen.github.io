$m=1$，序列最大的 $k$ 个字段和

```cpp
struct Solve1
{
	int s[N],f[N][12];
	void init()
	{
		mem(f,0),mem(s,0);
		for(int i=1;i<=n;i++)
			s[i]=s[i-1]+fr();
	}
	void solve()
	{
		init();
		for(int i=1;i<=n;i++)
			for(int p=1;p<=k;p++)
			{
				f[i][p]=f[i-1][p];
				for(int j=0;j<i;j++)
					f[i][p]=max(f[i][p],f[j][p-1]+s[i]-s[j]);
			}
		fw(f[n][k]);
	}
	
}Settle1;
```

$m=2$ 我们把它当做两个 $m=1$ 考虑

1. 当前枚举的两列不属于任何矩阵的最大值

2. 当前两列属于同一矩阵的最大值

3. 当前两列属于不同矩阵的最大值

4. 左边一列属于一个矩阵的最大值

5. 右边一列属于一个矩阵的最大值

设 $f_{i,j,k}$ 表示考虑第一列前 $i$ 行，第二列前 $j$ 行，选了 $k$ 个矩阵的最大值

$f_{i,j,k} \gets \max(f_{i-1,j,k},f_{i,j-1,k})$

然后分别作两边 $m=1$

最后考虑情况 $2$，即 $i=j$ 时，直接两行合并，做一遍 $m=1$

```cpp
struct Solve2
{
	int sl[N],sr[N],f[N][N][12];
	void init()
	{
		mem(sl,0),mem(sr,0),mem(f,0);
		for(int i=1;i<=n;i++)
			sl[i]=sl[i-1]+fr(),sr[i]=sr[i-1]+fr();
	}
	void solve()
	{
		init();
		for(int t=1;t<=k;t++)
			for(int i=1;i<=n;i++)
				for(int j=1;j<=n;j++)
				{
					f[i][j][t]=max(f[i-1][j][t],f[i][j-1][t]);
					for(int p=0;p<i;p++) f[i][j][t]=max(f[i][j][t],f[p][j][t-1]+sl[i]-sl[p]);
					for(int p=0;p<j;p++) f[i][j][t]=max(f[i][j][t],f[i][p][t-1]+sr[j]-sr[p]);
					if(i==j)
						for(int p=0;p<i;p++)
							f[i][j][t]=max(f[i][j][t],f[p][p][t-1]+sl[i]-sl[p]+sr[j]-sr[p]);
				}
		fw(f[n][n][k]);
	}
}Settle2;
```

------

根据上面的起始，我们也可以直接状压这一行的状态

$0$ 都不选

$1$ 只选左边

$2$ 只选右边

$3$ 都选，但是作为两个矩阵

$4$ 都选，作为同一个矩阵

$f_{i,j,0/1/2/3/4}$ 考虑前 $i$ 行，选了 $j$ 个矩阵，当前行状态为 $0/1/2/3/4$ 的最大值
