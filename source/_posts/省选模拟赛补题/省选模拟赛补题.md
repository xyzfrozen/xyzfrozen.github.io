# 省选模拟赛补题

## MX 新年省选

**T2**

烟花的配方可以看作一个长为 $n$ 的正整数序列 $a$ 。现在宵宫需要根据配方做出一场新的烟花，新的烟花可以看作一个长为 $n$ 的正整数序列 $b$ 。

对每个 $i=1,2, \cdots, n$ ，宵宫都已经预设好了两个正整数 $L_i, R_i$ ，表示她希望最终制作出的烟花 $b$ 能够满足 $b_i \in\left[L_i, R_i\right]$ ，保证 $L_i \leq R_i$​ 。

宵宫还指定了一个「相似值」 $k$ ，表示对于 $a$ 中的每个长度为偶数，且长度不超过 $2 k$ 的区间，设其为 $a_{i \cdots i+2 L-1}$ ，如果 $a_{i \cdots i+L-1}=a_{i+L \cdots i+2 L-1}$ ，那么新制作出来的烟花 $b$ 同样需要满足 $b_{i \cdots i+L-1}=b_{i+L \cdots i+2 L-1}$。

对每个 $1 \leq k \leq\lfloor n / 2\rfloor$ 求出，如果她指定的「相似值」为 $k$ ，有多少种合法的序列 $b$​ 满足她的要求，对 998244353 取模。

这个 T2 还比较可写，这里只是记录一下冰茶姬的套路，其余部分人尽皆知

套路来自这个题：[P3295 [SCOI2016] 萌萌哒 ](https://www.luogu.com.cn/problem/P3295)快速用冰茶姬合并 $(i,i+k)[l \leq i\leq r]$

这个题和本题基本一模一样，就是本题的 $L_i=1,R_i=n$ 的部分分，所以这个部分分到底在给什么？？？

我们考虑一个 `RMQ` 的经典方法，将 $[l,r]$ 拆成 $[l,l+2^d-1] \cup [r-2^d+1,r][d=\log_2^{r-l+1}]$ 这两段，分别进行 $4$ 个区间的两两合并

这么做的根据是因为并查集的合并**是满足结合律**，合并只要能完全覆盖即可，重不重没关系，同一个等价类内部合并无所谓

然后这个做法本质是可以看做代替线段树的 $tag$ 标记，我们练完边后直接下放标记即可

```cpp
signed main()
{

	for(int i=1;i<=n;i++) lg[i]=lg[i>>1]+1;
	for(int k=0;k<=lg[n];k++)
		for(int i=1;i+(1<<k)-1<=n;i++)
			pos[id[k][i]=++cnt]=i;
	iota(p+1,p+1+cnt,1);
	while(m--)
	{
		int l1=fr(),r1=fr(),l2=fr(),r2=fr();
		int d=lg[r1-l1+1];
		merge(id[d][l1],id[d][l2]);
		merge(id[d][r1-(1<<d)+1],id[d][r2-(1<<d)+1]);
	}
	
	for(int k=lg[n];k;k--)
		for(int i=1;i+(1<<k)-1<=n;i++)
		{
			int fa=find(id[k][i]);
			if(fa==id[k][i]) continue;
			merge(id[k-1][i],id[k-1][pos[fa]]);
			merge(id[k-1][i+(1<<k-1)],id[k-1][pos[fa]+(1<<k-1)]);
		}
	cnt=0;
	for(int i=1;i<=n;i++)
		if(find(i)==i) cnt++;
	fw(9*qkw(10,cnt-1)%Q);
	return 0;
}
```

```cpp
	{
```

```cpp
			Radix_sort(m);
			swap(fir,sec);
```

## MX 13联测-2

**T1**

给定 $m$ 条边 $(u,v,w)$ 和 $k$ 条限制 $(p,q,t)$，求有多少条边 $(u,v,w)$ 至少能有一条从 $p \to q$ 经过 $(u,v)$ 的路径，长度 $\leq t$

暴力枚举点对+边，判断 $d_{p,u}+w+d_{v,q} \leq t$，$O(n^4)$，$d$ 为最短路，注意还要判断交换 $(u,v)$ 的

处理一下式子，$d_{p,u}+w \leq t-d_{v,q}$，不妨预处理 $f_{p,v}=\max \{t-d_{v,q}\}$，只需要判断 $\max\{f_{p,v}\} \geq d_{p,u}+w$​

我们擅长的是单元素处理，所以需要绑定元素

```cpp
const int N=310;
int n,m,u,v,w,ans;
int G[N][N],f[N][N],g[N][N];
struct node{int i,j,l;};

{
	n=fr(),m=fr();
	memset(G,0x3f,sizeof G);

		u=fr(),v=fr(),E.pb({u,v,G[u][v]=G[v][u]=fr()});
	for(int k=1;k<=n;k++)
		for(int i=1;i<=n;i++)
			for(int j=1;j<=n;j++)
				G[i][j]=min(G[i][j],G[i][k]+G[k][j]);
	
	memset(f,-0x3f,sizeof f);
	for(int k=fr();k;k--)
	{
		u=fr(),v=fr(),w=fr();
		//d[u][i]+d[i][j]+d[j][v]<=w
		for(int j=1;j<=n;j++)
			f[u][j]=max(f[u][j],w-G[j][v]);
	}
	
	for(node &t:E)
	{
		int res=0,i=t.i,j=t.j,l=t.l;
		for(int u=1;u<=n;u++)
			res|=(f[u][j]>=G[u][i]+l);
		swap(i,j);
		for(int u=1;u<=n;u++)
			res|=(f[u][j]>=G[u][i]+l);
		ans+=res;
	}
	fw(ans);
	return 0;
}
```

**T2**

给定无根树，点有点权，边权 $1$，求到 $\min_{i=1}^n \max_{j=1}^n \{d(i,j)+a_j\}$

首先去掉点权，这个点就是树的中心，必然在直径上，否则它必然是直径上面某个点的子树

```
s----------u----t
		  |
		  v-....k
```

设 $v$ 在子树内的点距离它最长的为 $k$，$v$ 在子树外距离它最长的点的距离一定是 $\max (d_{s,v},d_{v,t})$ 否则直径会变长，因为 $d_{u,k} \leq d_{u,t} \Rightarrow d_{v,k} \leq d_{u,t} \leq d_{v,t}$，又 $\max (d_{v,s},d_{v,t}) \geq \max (d_{u,s},d_{u,t})$，从 $v$ 换到 $u$ 更优

我们还可以知道中心一定是上面中间的点，具有二分性

把点权转化成边权，我们给每个点挂一个虚拟儿子，到它的边权为点权

抽象一下模型：两个操作，修改边权，求直径，线段树可以动态维护形态不变的树的直径

求
$$
\begin{aligned}
D&=\max_{(u,v)} d_u+d_v-2 \times d_{lca(u,v)}\\
&=\max_{(u,v)} d_u+d_v-2\min_{ol_u \leq k \leq ol_v} d_k\\
&=\max_{1 \leq l \lt r \leq n} a_l+a_r- \min_{l \leq k \leq r} 2 \times a_k \,[a_i=d_{ol_i}]
\end{aligned}
$$
经典三值求最值，直接绑两个

[P4785 [BalticOI 2016 Day2\] 交换](https://www.luogu.com.cn/problem/P4785)

之前做过一个[典题](https://www.luogu.com.cn/problem/P2606)，这种 $i \to \lfloor \frac {i}{2} \rfloor$ 的操作都可以在二叉树上面，每个点的左右儿子分别是 $2\times i$ 和 $2 \times i+1$

我们考虑三个点中最小值的分布，不妨设当前点左儿子右儿子的权值是 $a,b,c$

交换方案共有以下几种

```
    a    |    b    |    c    |    c
  b   c  |  a   c  |  b   a  |  a   b
```

如果最小值是 $a \operatorname{or} b$ 的话，交换方案唯一，如果是 $c$，两种都有可能是最小字典序方案

暴力做是 $T(n)=4T(\frac n2)+O(n) \Rightarrow O(n^2)$ 的，主定理就是 $n^{\log_b^a}$ 和 $f(n)$ 大就选，等就带 $\log n$

我们考虑如何优化这个暴力，即讨论最小值在右子树的情况

设 $solve(x, y)$ 为将节点 $x$ 的权值改为 $y$，其余节点权值不变，仅对 $x$ 的子树按顺序交换得到的最小字典序方案中每个节点的权值构成的序列，$pos(x, y)$ 为 $solve(x, y)$ 序列中值为 $y$ 的数在哪个节点

有一个结论：当 $y_1 < y_2$ 时，$solve(x, y_1)$ 字典序小于 $solve(x, y_2)$ 字典序，$pos(x, y_1) \leq pos(x, y_2)$，且在 $solve(x, y_1)$ 和 $solve(x, y_2)$ 中编号小于 $pos(x, y_1)$​ 的节点权值相同

因为 $y_1$ 一定是当前是最小值才停止下放的，所以我们可以发现 $y_2$ 下放的更多或者在同一位置，而 $y_1$ 顶掉的一定 $\gt y_1$，$y_2$ 的祖先又比它小，所以可以得到在 $solve(x,y_1)$ 中的 $pos(x,y_1)$ 位置的数 $\gt y_1$，字典序更大

设次小值为 $v$，$pos(\text{leftchild}, v)$ 和 $pos(\text{rightchild}, v)$ 两者较小的的子树就是最小值应该在的位置

不妨考虑两种状态，设次小值为 $x$，最大值为 $y$​

```
A    x(左)     y（右)
B      y(左) x(右)  
```

最优情况是 $y$ 在 $x$ 前面

```
A    y(右)    x(左)
B  x(右)         y(左)
```

都可以发现只用判断 $pos$ 就可以判断整个的字典序

$pos$ 的计算和递归过程类似，同时我们发现一个节点被下放的位置只有子树大小个，总共的子树大小是 $O(n\log n)$ ，和线段树一样，所以总的状态数也是 $O(n\log n)$ 的，我们考虑记忆化这个 $pos$，总复杂度 $O(n\log n)$

```cpp
	if(ls>n) return x;

	else
	{
```
