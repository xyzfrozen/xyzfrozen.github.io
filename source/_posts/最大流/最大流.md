## Chapter 2 最大流

设 $G$ 可以构成的所有可行流的集合为 $S_1$，合法割的集合为 $S_2$

$f \in S_1$ 且 $|f|$ 最大的可行流则为最大流

$[S,T] \in S_2$ 且 $c(S,T)$ 最小的合法割则为最小割

根据 $1.4$ 的性质，则有 $\forall [S,T]$,$\;f\;|f|=f(S,T) \leq c(S,T)$

即 最大流 $\leq$ 最小割

### 2.1 最大流最小割定理

下文三个定理等价，可互相推

1. 可行流 $f$ 为最大流

2. 可行流决定的 $G'_f$ 中，不存在增广路径

3. $\exists [S,T]\;|f|=c(S,T)$  

------------

证明

$1 \to 2 \to 3 \to 1$

$1 \to 2$

反证法 

若存在增广路，则 $\exists |f'| \geq 0$，则 $|f+f'|$ 大于原最大流 $|f|$，矛盾

$2 \to 3$

取 $G'_f$ 中所有从 $s$ 出发能到的点，且 $c'(s,v) \gt 0$，组成集合 $S$

$T=V-S$

因为不存在增广路径，所以无法从 $s$ 走到 $t$ ，则 $s \in S$，$t\in T$

在 $G$ 中有

$1$

$\forall (u,v)\;u\in S\;v\in T\;f(u,v)=c(u,v)$

反证法

首先 $f(u,v) \leq c(u,v)$ 只需使 $f(u,v) \lt c(u,v)$ 矛盾

若 $f(u,v) \lt  c(u,v)$ 则 $c'(u,v) \gt 0$ 则 $v$  $\in S$，矛盾

$2$

$\forall (u,v) \;u\in T\;v\in S\;f(u,v)=0$

同上 若 $f(u,v) \gt 0$

则在 $G_f$ 中的反向边 $(v,u)$，有 $c'(v,u)=f(u,v) \gt 0$，则 $u \in S$，矛盾

则 $f(S,T)$ 根据公式，就等于 $c(S,T)$，则 $|f|=f(S,T)=c(S,T)$

![image](https://cdn.jsdelivr.net/gh/xyzfrozen/Cdn/img/202310010101714.png)

$3 \to 1$

$|f| =c(S,T) \geq$ 最大流 $\geq |f|$

$|f|=$ 最大流

------------

### 2.2 最大流

最大流 $FF$ 方法

1. $bfs$ 找增广路

2. 退流，利用增广路更新残留网络

即给定原流网络，维护残留网络

初始建边 正向边 $c$ ，反向边 $0$

若反向边流过 $k$ 流量，设原容量为 $c_1\;c_2$，则 $f(u,v) \to c_1-k$，$f'(v,u) \to c_2+k$

正向边下次最多能流的少了 $k$ ，反向边下次可以多退 $k$

$k$ 即为此条增广路径的最小容量，路径记录前驱即可

------------

注：最大流的时间复杂度纯唬人，算法效率极高，甚至可以跑 $n=1e4 \to 1e5$ 的数据

using namespace std;

const int N=1e3+10,M=2e4+10;

int n,m,s,t,u,v,w,ans,inf=2e9;
int h[N],e[M],ne[M],c[M],idx; //c 容量
int q[N],d[N],pre[N]; //d 流到当前点的最大流量 pre 前驱边
bool vis[N]; //vis 是否被遍历过

int fr(){ //double 不能快读！！！！
    int x=0,flag=1;
    char ch=getchar();
    while(ch<'0' || ch>'9'){
        if(ch=='-') flag=-1;
        ch=getchar();
    }
    while(ch>='0' && ch<='9'){
        x=x*10+(ch-'0');
        ch=getchar();
    }
    return x*flag;
}
void fw(int x){
	if(x<0) putchar('-'),x=-x;
    if(x>9) fw(x/10);
    putchar(x%10+'0');
}
int max(int a,int b){return a>b?a:b;}
int min(int a,int b){return a<b?a:b;}

void add(int a,int b,int w)
{
	e[idx]=b,ne[idx]=h[a],c[idx]=w,h[a]=idx++;
	e[idx]=a,ne[idx]=h[b],c[idx]=0,h[b]=idx++;
}

//1 寻找增广路
bool bfs()
{
	int hh=0,tt=-1;
	memset(vis,0,sizeof vis);
	q[++tt]=s,vis[s]=1,d[s]=inf; //设为比最大容量的值即可
	
	while(hh<=tt)
	{
		int x=q[hh++];
		for(int i=h[x];~i;i=ne[i])
		{
			int j=e[i];
			if(!vis[j] && c[i]) //未被遍历过 且边容量>0
			{
				vis[j]=1,d[j]=min(d[x],c[i]),pre[j]=i; //注意是前驱边
				if(j==t) return 1; //找到增广路
				q[++tt]=j;
			}
		}
	}
	return 0;
}

int EK()
{
	//2 更新残余网络 进行退流等操作
	while(bfs())
	{
		ans+=d[t];
		for(int i=t;i!=s;i=e[pre[i]^1])
			c[pre[i]]-=d[t],c[pre[i]^1]+=d[t];
	}
	return ans;
}

int main()
{
	n=fr(),m=fr(),s=fr(),t=fr();
	memset(h,-1,sizeof h);
	for(int i=1;i<=m;i++)
	{
		u=fr(),v=fr(),w=fr();
		add(u,v,w);
	}
	
	fw(EK());
	return 0;
}

### 2.4 $Dinic$

$Dinic$ 算法 $EK$ + 分层图优化 $O(n^2m)$

如何优化 $EK$ 的复杂度呢？

考虑一次求多条增广路，直接爆搜，但是可能会遇到环的情况又没法用 $vis$ 数组标记

这样从环外一点到环上，每次耗掉环上一点容量，增广路就会有很多条

为了降低时间复杂度，考虑引入分层图，同时规定每一个节点只能从当前层走到下一层，这样就不会绕圈子了

先用 $bfs$ 处理出每个点到 $s$ 的最短路距离，借助 $d$ 对残留网络分层，同时也可以告诉我们有没有增广路，再用 $dfs$ 找出所有能增广的路径

考虑进一步优化：

$1$ 当前弧优化

$dfs$ 过程中每次都需要枚举当前点的可达点，如果它的某一条边已经满了，无法再流流量了，下次就不用枚举了

那么我们规定一个增加增广路的顺序，按照这个点的邻接表的顺序依次满流

那么用个 $cur$ 数组记录下当前点第一个没满流边的编号，每次从 $cur_x$ 开始遍历即可

记得每次初始化 $cur_x=h_x$

然后每次遍历 $v$ 的时候开个剩余流量 $rest$，当 $rest \gt 0$ 的时候才继续循环

正确性：

不妨讨论代码中 $find(j,min(c_i,rest))$ 的返回值

若为 $c_i$ 显然满流

若为 $rest$ 则 $u$ 不能再流向 $t$ 流量了，那么这次 $for$ 循环因为 $rest==0$ 就直接退出了，下次还是从这条边开始

若为 $\lt min(c_i,rest)$ 则 $j$ 流向源点的某条边也已经满流，等价于这条边满流

$2$ 分层图距离优化

每次不管 $d>d_t$ 的点，优先走距离较短的路径，在之后某次 $bfs$ 的时候再处理

	{

int find(int x,int ltf)
{
	if(x==t) return ltf;
	int rest=ltf;
	for(int i=cur[x];~i && rest;i=ne[i])
	{
		cur[x]=i; //更新当前弧
		int j=e[i];
		if(d[j]==d[x]+1 && c[i])
		{
			int k=find(j,min(rest,c[i]));
			if(!k) d[j]=-1; //不可到达，删除此点
			else c[i]-=k,c[i^1]+=k,rest-=k;
		}
	}
	return ltf-rest; //流向它的 - 未留向 t 的
}

int dinic()
{
	int flow,ans=0;
	while(bfs()) //1 建立分层图 确认有增广路
		while(flow=find(s,inf)) ans+=flow; //2 找到所有增广路累加
	return ans;
}

{

	for(int i=1;i<=m;i++)
	{
		u=fr(),v=fr(),w=fr();
		add(u,v,w);
	}
	
	fw(dinic());
	return 0;
}

### 2.5 最大流最小割的相关分析和思考方式

最大流最小割的难点在于建图

一般问题为求某个问题的最值，设此题所有可行解的集合为 $P$

则我们要做的就是构造一个图 $G$

若求最大值，便使可行流与可行解一一对应

即证明任意可行解对应某可行流，任意可行流可转化为某可行解

则可行解集合最大值等价于最大可行流

若求最小值，便使合法割与可行解一一对应

即证明任意可行解对应某合法割，任意合法割可转化为某可行解

则可行解集合最小值等价于最小合法割

### 2.6 二分图

#### 2.6.1 二分图匹配

比匈牙利算法更快

例题 $1$ [飞行员配对方案问题](https://www.luogu.com.cn/problem/P2756 "飞行员配对方案问题")

上文均为模板，从本题开始加入建图的学习

$Step 1$

首先我们确定源点和汇点

本题有两个点集，外籍飞行员和本土飞行员

每一个外籍飞行员都只能出现在一个匹配里，也就是每一个外籍飞行员只能用一个，这就提示我们连一条从源点到每个外籍飞行员的容量是 $1$ 的边，同理每个英国飞行员也只能用一次，那我们就从英国飞行员向汇点连一条容量是 $1$ 的边。

然后每个外籍飞行员都可以匹配指定的一些英国飞行员，由于每个外籍飞行员和英国飞行员都只能用一次，因此每条边都只能用一个，所以我们可以从每个外籍飞行员向他匹配的所有英国飞行员连一条容量为 $1$ 的边。

至此建完图

$Step 2$

证明可行解与可行流一一对应

可行解 $\to$ 可行流

设可行解选择的边集为 $E$

$\forall (u,v) \in E$ 我们选择 $(s,u)\;(u,v)\;(v,t)$ 三条边，这样就构造出了一个流

是否可行？

容易发现满足容量限制和流量守恒

可行流 $\to$ 可行解

对于任意可行流

考虑外籍飞行员点集内的一点 $x$

若 $f(s,x)=0$ 则它不会流入，对应所有它可配对的点都不选择

若 $f(s,x)=1$ 则它只会流入一个对面的点，且对面的点一定不会被除 $x$ 外的点选择，违背这两点任意一点就无法满足容量限制

----------

时间复杂度分析

$O(nm) \to O(\sqrt nm)$

匈牙利算法本质上是简化的 $EK$ 算法

每次选择一个点，然后遍历可达点 $v$

$match_v$ 就是反向边，继续递归相当于一个退流的过程

那么显然 $dinic$ 是比 $EK$ 快的

例题 $2$ [P3254](https://www.luogu.com.cn/problem/P3254 "P3254")

二分图多重匹配

$Step 1$

还是和上个题一样，单位和圆桌视为两个点集

中间就是每个单位可以排人去所有单位，每个圆桌只能去一个，所以容量是 $1$

我们发现每个单位可以派很多个人，那么 $(s,x)$ 的容量就设为 $a_x$ 即可，代表可以派这么多人

类似的，每个桌子可以容纳 $b_x$ 的人，$(x,t)$ 的容量就设为 $b_x$ 即可，代表最多容纳这么多人

$Step 2$

和上题类似即可

那么题目的意思翻译过来就是 $(s,x)$ 满流

等价于最大流等于人数和

所以本题是最大流

### 2.7 上下界流

#### 2.7.1 无源汇上下界可行流

无源点汇点，容量限制改为 $c_l(u,v) \leq f(u,v) \leq c_u(u,v)$，问是否存在可行流满足流量守恒

$l$ 表示下界 $lower$，$u$ 表示上界 $upper$

我们考虑将原图 $G(V,E)$ 和 $f$ 转化成 $G'(V,E')$ 和 $f'$ 的形式，且 $E'$ 只有上界 $c'(u,v)$

然后用 $G'$ 来求原图的 $f$ 即可

首先 $c_l(u,v) \leq f(u,v) \leq c_u(u,v)$ 等价于 $0 \leq f(u,v)-c_l(u,v) \leq c_u(u,v)-c_l(u,v)$

此时 $f'$ 满足了容量限制 $c'(u,v)=c_u(u,v)-c_l(u,v)$，但不一定满足流量守恒

因为本来是 $\Sigma f(u,x)=\Sigma f(x,v)$

现在变成了 $\Sigma (f(u,x)-c_l(u,x))$ 和 $\Sigma (f(x,v)-c_l(x,v))$

解决这个问题也很简单

设 $c_1=\Sigma c_l(u,x)$，$c_2=\Sigma c_l(x,v)$

如果 $c_1 \gt c_2$ 入的流量就会变少，直接从 $s$ 连一条容量为 $c_1-c_2$ 的边即可

反之向 $t$ 连一条 $c_2-c_1$ 的边

举个例子：$a$ 到 $b$ 流 $1$，说明要有另一条路从 $b$ 到 $a$ 流 $1$，形成一个循环。所以可以建立一个源点和汇点，从 $S$ 到 $b$ 建立流 $1$，从 $a$ 到 $T$ 建立流 $1$。

就像是本来 $G'$ 是一个残图，它的流量每个点到处流，但是每个点又不能储存能量，就搞个 $s\;t$ 把这些多了的流量吸收了

现在只需要证明 $G$ 与 $G'$ 集合等价且一一对应

首先给 $f'$ 全部加上 $c_l(u,v)$ 满足了容量限制

那么如果从 $s$ 流出去的流量全部满流，就满足了流量守恒

那么我们在 $G'$ 跑最大流，然后每个都加上 $c_l(u,v)$ 就转化成了 $G$ 的最大流

问题转化为 $|f'|$ 是否等于 $\Sigma c(s,x)$

一个小 $trick$：跑完最大流后，想知道正向边流量，就等价于反向边流量 $c[i\;xor\;1]$

[参考文献](https://zhuanlan.zhihu.com/p/324507636 "参考文献")

#### 2.7.2 有源汇上下界可行流

我们可以加一条 $t \to s$ 的边，并设 $c_u(t,s)=+\infty$，$c_l(t,s)=0$ 即可

通过这种方式，我们就保证了源点和汇点都是流量守恒的，将源点和汇点转换成了普通点，构成循环流

这样就转化成了无源汇上下界可行流，再新建 $s'\;t'$ 即可

若有解，则 $|f|=f(t,s)$

#### 2.7.3 有源汇上下界最大流

同上 $add(t,s)$ 建图，考虑如何求最大流？

一个 $naive$ 的想法，直接在 $G'$ 跑最大流

但是根据定义，$|f'| \to (s',t')$，$|f'|$ 与 $(s,t)$ 无关了，这并不能得到 $|f|$

那么我们用 $(s',t')$ 找一个可行流，再把所有 $(s',x)\;(x,t')$ 和 $(s,t)$ 边删掉，再在对于 $G'$ 仅去边的残留网络 $G''_f$ (也是 $G$ 的残留网络）上再跑最大流

设我们在 $G''_f$ 上面跑的最大流 $f_0$，则 $G$ 的最大流 $f=f'+f_0$

相当于我们先把 $G$ 通过加边和新建 $(s',t')$ 变成了 $G'$ 跑出来了一个可行流，这个流去掉了 $(s',t')$ 和 $(s,t)$ 恢复成 $G$ 也是满足下界和流量守恒的，因为所有 $(s',x)\;(x,t')$ 都是满流

然后我们在 $G''_f$ 上面，看看能不能再贪点，混点流回来，因为是在残留网络上面，所以我们不担心超过容量限制

$trick$ 删边直接改源点汇点，$(s',t') \to (s,t)$，然后把 $c(s,t)=c(t,s)=0$，因为就算流到 $(s',t')$ 了，残留网络全是满流，那么 $s'$ 回到原网络的边的容量都是 $0$，流向 $t'$ 的也同理，不会流回原网络

### 3.1 ISAP

普通的题目用 $Dinic$ 已经够用了，但如果出题人丧心病狂卡它，还是会 $gg$

$ISAP$

全称 $Improved\;Shortest\;Augment\;Path$

对于 $dinic$ 的 $dfs$ 过程我们无法优化，~~否则就变成 $EK$ 了~~

考虑对 $bfs$ 进行优化，我们动态维护划分层次的过程

我们只用一次从 $t$ 反向跑 $bfs$ 划分层次，则 $s$ 的层次最高为 $n-1$ ( $t$ 的层次为 $0$ )

考虑什么时候一个点的层次会变，当且仅当它不能通过下一层的可达点流向 $t$ 了

所以我们在一个点遍历玩所有可达点后，如果 $rest \gt 0$ 则说明下一层所有儿子满流，我们就提升它，看有没有能够流向同层次的，一直重复这个过程即可

因为根据 $bfs$ 特性，$x$ 的可达点层次只可能 $\geq$ 初始的 $x$ 层次 $-1$

当 $s$ 的层次 $== n$ 的时候即可结束程序

注意每次提升层次都要重置 $cur$ 之前的儿子可能是因为不在下一层而跳过的，现在提升层次就可能遍历到了

$gap$ 优化

我们记层次为 $x$ 的点个数为 $cnt_x$，当 $cnt_x==0$ 的时候，显然是之前该层点全部满流，无增广路，直接将 $s$ 的层次设为 $n$ 结束程序即可

### 3.2 HLPP

对 $ISAP$ 的改进

我们考虑一种算法，和源点直接连通的点假设有 $c(s,x)$ 的水量

这些点不断向其它点运水

但是这样会出现两个点反复横跳的情况，为了避免这样的情况，我们也和 $ISAP$ 一样引入层次

水从高处向低处流，如果一个点推完了可达点（不含 $s\;t$），还有余流，我们就把它提升层次，看还能不能找到点继续流

初始设 $s$ 的层次为 $n$，等有点层次到了 $n+1$ 就会根据某些路径把这些水退回到 $s$

最后 $flow_t$ 就是答案

然后每次层次更新就是可达点里面层次最小的 $+1$，让他尽可能的推流

然后用优先队列维护层次最大的点更新，再把可达点入队，直至队列为空，注意 $s\;t$ 不入队

初始把所有 $s$ 可达点加入队列，进行推流

$gap$ 优化同理，该断层以上点均不能推到汇点，直接高度设为 $n+1$，流向 $s$

注：$bfs$ 类型求最大流，$EK\;HLPP$ 都不用当前弧优化

先求下最大流 $f$，不难发现，只有满流的边才有可能成为关键边

则一个满流的边想成为关键边的条件为 $s \to u$ 存在增广路，$v \to t$ 存在增广路

那么我们直接在 $G'_f$ 中找 $s$ 可达点和 $t$ 可达点，然后枚举正向边即可，这个复杂度 $O(m)$

注意从 $t$ 找的时候是看反向边（也就是从 $s$ 看的正向边）$c$ 是否为 $0$

[题目](https://www.luogu.com.cn/problem/P2766 "题目")

第一问 $LIS$ 暴力即可，设 $LIS$ 长度为 $L$

第二问

如果把序列看成 $n$ 个点的话，我们发现主要的矛盾就是每个点只能用一次，这就让我们联想到网络流

和点有关的我们直接拆点，限制每个点只能用用一次

考察最长不降子序列的流程，我们转移是从 $j \to i\;\;(a_j \leq a_i\;j \lt i)$，我们不妨从 $j$ 向 $i$ 连一条边

问题等价于，有多少条长度为 $L$ 的流路径

如何统计呢，发现一个条路径的贡献可以全部在最后一个点统计，所有我们可以利用第一问的 $f_i$ 数组解决问题

我们从 $s$ 向所有 $f_i=1$ 的点连一条边，从 $f_i=L$ 的点向 $t$ 连一条边

所有边的容量都是 $1$

那么我们需要改下加边的条件，当且仅当 $f_j+1==f_i$，且 $a_j \leq a_i$ 注意是从 $j$ 的出点连

因为最后跑出来的一条路径，如果无法达成 $L$ 其实是不合法的，要想跑出来 $L$ 只能从最长的前驱跑，而如果达到了 $L$，最长的任意儿子都是合法路径，得证

第三问

我们只用把第一个点和第 $n$ 个点限制放开，把他们的入点到出点的边容量改为 $inf$

同时如果源汇有连边，也改成 $inf$

那么之前的不重复肯定也满足条件，现在只是看再能不能跑出来合法增广路，所以我们直接在残留网络上面跑就行了

我们发现一个点想要到柱子上面去，要么新开柱子，要么合并到之前的点上面

发现一个点有两个操作，我们如果把柱子也看成点的话这就是一个图，我们考虑拆点网络流

我们规定自立门户就是流向汇点，那么 $s$ 向入点连边，出点向 $t$ 连边，然后 $i \to j'[i+j=x^2]$

### 3.4 problem

[题目](https://www.acwing.com/problem/content/2239/ "题目")

发现这个猪圈和顾客类似一个二分图的玩意，又是求最大，我们不难发现是最大流

我们发现每个顾客的行为都局限在一天内，并且每天只有一位顾客

所以我们可以根据时间建立分层图，每一层表示每位顾客买完之后的猪圈状况

初始 $s$ 向第 $0$ 天的猪圈连一条容量 $w_i$ 的边

然后每个顾客都是买之前别人剩下的，所以我们可以从顾客向 $t$ 连一条容量 $inf$ 的边

假设顾客可以操作的猪圈之一为 $j$，当前第 $i$ 天
