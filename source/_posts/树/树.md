## 树

树具有很好的性质，包括但不限于：无根性，连通性，唯一路径等

考虑树上的题目，一般通过叶子节点寻找边界条件和思路

同时，树本质上是一个关于点和边的集合运算，其本身具有一定的贡献可加性

注意做 $dp$ 的时候，如果是先算子树再算自身的写法，前面就可以乱搞，但是如果先算了自身再算子树，就需要加入子树时每次和之前的子树+自身取个 $min$

## 点集

点集：关于点的集合，记为 $T$

$T(u)$ 所有点都在 $u$ 及其子树内的集合

$ans=max\;\operatorname{or}\;min\;\operatorname{or}\;\Sigma\;\operatorname{or}\;...\;val_{T(u)}$

## 路径集

路径集：关于树上一条路径的集和，记为 P

$P(u)$ $u$ 为该路径的 $lca$ 的集合

------------

## 点(路径)集的基本应用

也可称为 $lca$ 集合计算

主要为 $dp$ 和计数问题

包括当前点选不选和子树中点选不选两种集合定义方案

如果选择子树中点(路径)集计算的话，一般在 $lca$ 处统计方案

一般 $dp$ 转移就是考虑新增子树 $v$ 的贡献

$T(u)$ 和 $C_u{T(1)}$ 以及 $P(u)$

补集计算是受 $fa$ 影响，必须在 $T(u)$ 当前统计

如果不受影响，可以直接全部加到 $T(1)$ 上，一次性计算即可

路径集和点集差不多

注：判断叶子节点

改为考虑子树内选不选

$f_{u,1}$ 当前子树内至少选了一个点且所有选择的点与 $u$ 联通的方案

$f_{u,0}$ 完全不选，辅助计算下

初始化

$$
\begin{cases}
f_{u,0} \leftarrow 2^{ed}\\
f_{u,1} \leftarrow 2^{ed} \cdot (2^{dot}-1)
\end{cases}
$$

点去掉全空的状态

初始化的时候都是 $T(u)$ 中 $u$ 选择的状态，$u$ 不选的状态让儿子中有点，保证 $T(u)$ 不为空集即可

考虑加入新子树 $v$ 的贡献

**即 $T(u) += T(v)$**

**什么在转移时会造成影响呢**

当 $T(v)$ 不为空集时，$T(v)$ 中点需要与 $v$ 连通，且 $v$ 需要与 $u$ 连通，这是为了让 $v$ 中的点与整棵树其余部分连通。否则，$u$ 与 $v$ 间的边属于可有可无

但是这样父亲似乎会统计到儿子的答案，造成答案变多，可以容斥，也可以加入一些限制条件

**我们把 $u$ 到父亲的边强制断掉**，这样就可以只考虑 $T(u)$ 内部的贡献了，同时任意一种点集方案，都会被在 $lca$ 处计算到，保证正确性

在向上走的时候，强选 $ed(u,v)$ 这样就保证不会重复

记 $cnt_u$ 为未缩点图该点及子树总边数

$$
\begin{aligned}
ans & \leftarrow f_{u,1} \times 2^{m-cnt_u-1} & u\not=1\\
ans & \leftarrow f_{u,1} & u=1
\end{aligned}
$$

$2^{m-cnt_u-1}$ 为 $C_u{T(1)}$ 的贡献，$-1$ 是断父边

$$
val_{T(u)}=f_{u,1} \times f_{C_u\,{T(1)},0}
$$


这里的计算方式就是和补集计算

因为 $u$ 向上转移的时候，也有两种方案，而不是简单的相乘

$fa$ 向上全部不选点和至少选择一个点

和补集计算是解决向上不选点的方案

因为这种情况 $fa$ 没法处理

至少选一个则为 $T(fa)$

这两类方案集合，通过 $u$ 到 $fa$ 这条边选不选来划分

------------

**现在考虑 $dp$ 转移**

设集合未转移之前为 $f'_{u,0}$ $f'_{u,1}$ $T'(u)$

**先考虑简单的 $f_{u,0}$**

$edge(u,v)$ 可不选

$$
f_{u,0} \leftarrow 2\times f'_{u,0} \times f_{v,0}
$$

------------

**然后是 $f_{u,1}$**

$T'(u)$ 必选

不选择 $T(v)$ 边可不选

$$
f_{u,1} \leftarrow 2\times f'_{u,1} \times f_{v,0}
$$
选择 $T(v)$ 边必选

$$
f_{u,1} \leftarrow f'_{u,1} \times f_{v,1}
$$
$T'(u)$ 不选 边必选

$$
f_{u,1} \leftarrow f'_{u,0} \times f_{v,1}
$$
注意这种情况，$f_{u,0}$ 自身不选

为什么不会和 $f_{v,1} \cdot 2^{m-cnt_v-1}$ 的方案中一种选边恰好为 $f_{u,0}$ 的方案重复？

这两种方案之中，$ed(u,v)$ 被保护了，即强制选择，$v$ 的方案中，这条边强制不选，是两种方案

$O(n)$

------------

### [P8290 [省选联考 2022] 填树](https://www.luogu.com.cn/problem/P8290)

本题主要是围绕值域限制的一个树形 $dp$

同样在 $lca$ 处统计方案

题目提示了**实际上是修改一条路径**

因为 $l \geq 1$ 所以只要选定了起点，就只能向下或者向上一直走，向下当然中途碰到多个子树可以选择从哪个子树向下

所以可以考虑树上任意一种路径的贡献，枚举路径 $lca$ 方案集合，也可以说是 $\Sigma val_{P(u)}$

即统计树上所有链的方案

**本题因为具有值域性质，可以直接枚举路径的值域 $L\;R$ 计算**

然后使用换根 $dp$ 的方式更换路径最高点

------------

**首先对这个 $P(u)$ 分个类**

$1$ 不跨过 $u$ 的，即单链 状态为 $0$

$2$ 跨过 $u$ 的，即双链 状态为 $1$

根据题意

$f_{u,0/1}$ 方案

$w_{u,0/1}$ 方案权值之和

初始化

当前可选区间 $[l,r]$

$$f_{u,1}=f_{u,0}=r-l+1=ov$$

$$w_{u,1}=w_{u,0}=\frac{(l+r) \cdot (r-l+1)}{2}=os$$

注意初始化都是强选当前点的，在下面转移的时候，直接把单链的贡献加到了双链上面

考虑任意一种合法路径，我们可以按照这个路径的最小值先划分一次集合，再根据 $lca$ 继续划分集合，这里可以**考虑容斥**的方式解决，保证一定 $P(u)$ 一定有一个点取到路径最小值，这样就不会算重复了

$$ans1=\Sigma\;f_{u,1} \in [vl,vr] - f_{u,1} \in [vl+1,vr]$$

$$ans2=\Sigma\;w_{u,1} \in [vl,vr] -w_{u,1} \in [vl+1,vr]$$

------------

**考虑新加入子树 $v$ 的贡献**

记转移前 $P'(u)$ $f'_{u,0}\;f'_{u,1}$

单链可以拼成双链

$$f_{u,1} \leftarrow f'_{u,0} \cdot f_{v,1}$$

单链可以和自己拼成新单链

$$f_{u,0} \leftarrow f'_{u,0} \cdot f_{v,0}$$

然后权值也相同

$$w_{x,1} \leftarrow f'_{x,0} \cdot w_{v,0} + f_{v,0} \cdot w_{x,0}$$

$f'_{x,0}$ 的所有单链方案中，$w_{v,0}$ 都会出现一次

同理 $f_{v,0}$ 的所有单链方案中， $w_{x,0}$ 也都会出现一次

可以假设 $f'_{x,0}=a,b,c,d$，$f_{v,0}=x,y,z$

那么 $val_{a,x}={w_x+w_a}$ 

然后所有方案累加推下最后结合律一下就行了

同理 $w_{x,0} \leftarrow w_{v,0} \cdot ov + f_{v,0} \cdot os$

就是分开算儿子的贡献和父亲的贡献，最后一个结合律就行

$O(wn)$

------------

### [P8981 「DROI」Round 1 距离](https://www.luogu.com.cn/problem/P8981 "P8981 「DROI」Round 1 距离")

最远点对即为直径的两个端点

那么每个点贡献，为该点被树上的直径覆盖了多少次

此为路径集运算，考虑 $dp$

------------

首先不妨两次 $dfs$ 找到直径长度，记为 $L$

$d_x$，$P(x)$ 集合内，从 $x$ 向下走的最长路径 

$cnt_x$，最长路径的个数，$cnt1=cnt_x$ 最长链个数，$cnt2$ 次长链个数

------------

**然后对直径划分下集合，不跨过 $x$ 的和跨过 $x$ 的两类**

考虑把答案统计到最长链上面

$cover_x$，$P(x)$ 中最长链被覆盖次数，最后乘上 $cnt_x$ 就是实际被直径覆盖的次数

$dot_x$，$P(x)$ 辅助计算多个长链的情况，此时儿子和父亲单独计算

**$1$ 不跨过，即 $x$ 为直径的端点**

这种情况 $x$ 只可能有一个儿子，否则 $x$ 不可能为直径的端点

这种情况的充要条件是 $d_v+1==L$

则 $cover_x \leftarrow 1$ 最后相当于走了 $cnt_x$ 次

代表 $P(v)$ 中 $d_v$ 

**$2$ 跨过，即 $x$ 为直径的 $lca$**

一条直径一定是一个点的最长链和次长链(或两条最长链)组合而成的

规定 $P(u)'$ 和 $P(v)$ 的转移顺序为和之前的组合，避免算重复

**$2.1$ $v$ 在最长链上**

最长链+次长链的组合方式

最长链+最长链的组合方式

两种分讨，具体看代码

**$2.2$ $v$ 在次长链上**

如果能和最长链拼成直径，当前 $d_v$ 就会被覆盖 $cover_v \leftarrow cnt1$，等价于走了 $cnt1 \times cnt_v$次

此时父亲也会被覆盖，在上面的最长链+次长链情况会被统计到

------------

那么最终的做法就是先遍历儿子求 $d_x\;cnt_x$，然后再遍历一次，每个子树和之后的子树组合计算，最后差分加和，把最长链上的儿子都加上自己的 $cover_x$，因为是统计到最长链上的，所以只要父亲走了，儿子必定走

$O(n)$

```cpp
#include<bits/stdc++.h>
#define int long long
#define pt putchar(' ')
#define nl puts("")
#define pi pair<int,int>
#define pb push_back
#define go(it) for(auto &it:as[x])
using namespace std;

const int N=5e6+10,Q=998244353;
int n,k,u,v,now,L,ans;
int d[N],cnt[N],cover[N],dot[N];
vector<int> as[N];

int fr(){
    int x=0,flag=1;
    char ch=getchar();
    while(ch<'0' || ch>'9'){
        if(ch=='-') flag=-1;
        ch=getchar();
    }
    while(ch>='0' && ch<='9'){
        x=x*10+(ch-'0');
        ch=getchar();
    }
    return x*flag;
}
void fw(int x){
	if(x<0) putchar('-'),x=-x;
    if(x>9) fw(x/10);
    putchar(x%10+'0');
}
int max(int a,int b){return a>b?a:b;}
int min(int a,int b){return a<b?a:b;}

void dfs(int x,int rt)
{
	d[x]+=d[rt];
	if(d[x]>d[now]) now=x;
	go(it) if(it!=rt) d[it]=1,dfs(it,x);
}

void dp(int x,int rt)
{
	int mch1=0,mch2=0,cnt1=1,cnt2=0;
	//maxchain && cnt 不妨考虑叶子节点分讨cnt
	go(it)
	{
		if(it==rt) continue;
		dp(it,x);
		if(d[it]+1>mch1) mch2=mch1,cnt2=cnt1,mch1=d[it]+1,cnt1=cnt[it];
		else if(d[it]+1==mch1) cnt1+=cnt[it];
		else if(d[it]+1>mch2) mch2=d[it]+1,cnt2=cnt[it];
		else if(d[it]+1==mch2) cnt2+=cnt[it];
	}
	
	cnt1%=Q,cnt2%=Q;
	int t=cnt1;
	//直径一定是一个点出发的最长链+次长链
	go(it)
	{
		if(it==rt) continue;
		//儿子在最长链
		if(d[it]+1==mch1)
		{
			//不跨过 x 的最长链为直径 只有一个儿子 不会算重
			if(mch1==L) cover[x]++; //+=cnt[x]
			//跨过 x 的直径
			//只有一条最长链 看能不能和次长链凑成直径
			else if(!(cnt1-cnt[it]) && mch1+mch2==L)
				cover[x]+=cnt2; //+=cnt[x]*cnt2
			//多条最长链 一定是最长链和最长链凑成直径
			//和后面的最长链拼起来 此时不能直接统计到最长链上面 分开计算
			else if(cnt1-cnt[it] && (mch1<<1)==L) 
				cover[it]+=cnt1-cnt[it],t-=cnt[it],dot[x]+=cnt[it]*t;
		}
		//儿子在次长链 并且和最长链构成直径
		//此时次长链也是儿子中的最长链 而父亲在上面的第二个 if 统计了
		if(d[it]+1==mch2 && mch1+mch2==L) cover[it]+=cnt1;
	}
	
	d[x]=mch1,cnt[x]=cnt1%Q,cover[x]%=Q;
}

void calc(int x,int rt)
{
	go(it)
	{
		if(it==rt) continue;
		if(d[it]+1==d[x]) cover[it]+=cover[x];
		calc(it,x);
	}
	cover[x]=(cnt[x]*cover[x]%Q+dot[x])%Q;
}

signed main()
{
	n=fr(),k=fr();
	for(int i=1;i<n;i++)
	{
		u=fr(),v=fr();
		as[u].pb(v),as[v].pb(u);
	}
	
	dfs(1,0);
	memset(d,0,sizeof d);
	int t=now;now=0;
	dfs(t,0),L=d[now];
	
	dp(1,-1);
	calc(1,-1);
	
	for(int i=1;i<=n;i++)
	{
		if(k==1) ans=(ans+cover[i])%Q;
		else ans=(ans+((cover[i]*cover[i])%Q))%Q;
	}
	fw(ans);
	return 0;
}
```

### [P8127 [BalticOI 2021 Day2] The Xana coup](https://www.luogu.com.cn/problem/P8127 "P8127 [BalticOI 2021 Day2] The Xana coup")

与操作顺序无关

首先把这个诈骗的条件转换一下，每个点至多操作一次，（大于等于两次等价于没变），问题等价于最少需要多少个点操作

显然有 $O(n^3)$ 的高斯消元，但是我们知道树上高斯消元可以通过类似树形 $dp$ 的方式变成 $O(n)$

注：大概只有游走题用通式比较方便，一般的题直接 $dp$ 就行

**考虑下我们需要的状态**

 1. 我们要向上转移，所以要把当前点和子树的全部操作累加到当前点
 2. 当前点是否操作

**因为父亲要控制儿子，必须知道儿子的子树和，而儿子对父亲是否有影响也要上传上去**

分类讨论

$f_{x,0/1,0/1}$ 节点 $x$ 自己操作完后是 $0/1$ 当前是否操作

初始化叶子节点

$$f_{x,w_x,0}=0\;f_{x,w_x\,\oplus 1,1}=1$$

$x$ 表示当前点，$v$ 表示 $x$ 任意子树的根

还是考虑加入一个子树的贡献，然后把所有子树合起来，最后算上自己，这就是一般套路

考虑子树如何转移到根

所有 $v$ 的操作的对 $x$ 的影响可以缩小到只和操作次数的奇偶性相关

1. 若 $x$ 不进行操作，根保持原来的状态，那么就要满足它的子树的根都必须是零，且有偶数个进行了操作

2. 若 $x$ 不进行操作，根不保持原来的状态，那么就要满足它的子树的根都必须是零，且有奇数个进行了操作

3. 若 $x$ 进行操作，根不保持原来的状态，那么就要满足它的子树的根都必须是一，且有偶数个进行了操作

4. 若 $x$ 进行操作，根保持原来的状态，那么就要满足它的子树的根都必须是一，且有奇数个进行了操作

------------

然后维护子树和

上述的子树状态有，操作次数是奇/偶 带上父亲是否保持原状态

则设 $g_{0/1,0/1}$ 当前操作数是奇/偶 父亲是否操作（儿子是否操作可以通过儿子的 $f$ 第二维得到）

$$
g_{0,0} \leftarrow \min (g'_{1,0}+f_{v,0,1},g'_{0,0}+f_{v,0,0})\\

g_{1,0} \leftarrow \min (g'_{1,0}+f_{v,0,0},g'_{0,0}+f_{v,0,1})\\

g_{0,1} \leftarrow \min (g'_{1,1}+f_{v,1,1},g'_{0,1}+f_{v,1,0})\\

g_{1,1} \leftarrow \min (g'_{1,1}+f_{v,1,0},g'_{0,1}+f_{v,1,1})\\
$$


初始化先搞一个儿子当初始的，转移每次开个局部变量拷贝就行了

$$
g_{0,0}=f_{v,0,0}\\

g_{1,0}=f_{v,0,1}\\

g_{0,1}=f_{v,1,0}\\

g_{1,1}=f_{v,1,1}\\
$$


------------

$$
f_{x,w_x\,,0} \leftarrow g_{0,0}\\

f_{x,w_x\,\oplus 1,0} \leftarrow g_{1,0}\\

f_{x,w_x\,,1} \leftarrow g_{1,1}+1\\

f_{x,w_x\,\oplus 1,1} \leftarrow g_{0,1}+1\\
$$

注意 $inf$ 开个 $1e6$ 就行了

```cpp
const int N=1e5+10;

vector<int> as[N];

void dfs(int x,int rt)
{
	if(as[x].size()==1 && as[x][0]==rt)
	{
		f[x][w[x]][0]=0;
		f[x][w[x]^1][1]=1;
		return;
	}
	
	int h[2][2],g[2][2];
	bool flag=0;
	go(v)
	{
		if(v==rt) continue;
		dfs(v,x);
		if(!flag)
		{
			flag=1;
			h[0][0]=f[v][0][0];
			h[1][0]=f[v][0][1];
			h[0][1]=f[v][1][0];
			h[1][1]=f[v][1][1];
			continue;
		}
	   	
		//先算子树类的 不用和之前的取 min
		memcpy(g,h,sizeof g);
		h[0][0]=min(g[1][0]+f[v][0][1],g[0][0]+f[v][0][0]);
		h[1][0]=min(g[1][0]+f[v][0][0],g[0][0]+f[v][0][1]);
		h[0][1]=min(g[1][1]+f[v][1][1],g[0][1]+f[v][1][0]);
		h[1][1]=min(g[1][1]+f[v][1][0],g[0][1]+f[v][1][1]);
	}
	
	f[x][w[x]][0]=min(f[x][w[x]][0],h[0][0]);
	f[x][w[x]^1][0]=min(f[x][w[x]^1][0],h[1][0]);
	f[x][w[x]][1]=min(f[x][w[x]][1],h[1][1]+1);
	f[x][w[x]^1][1]=min(f[x][w[x]^1][1],h[0][1]+1);
}

	{
		u=fr(),v=fr();
		as[u].pb(v),as[v].pb(u);
	}
	for(int i=1;i<=n;i++) w[i]=fr();
	
	for(int i=1;i<=n;i++)
		for(int j=0;j<=1;j++)
			for(int k=0;k<=1;k++)
			 	f[i][j][k]=1e6;
	dfs(1,-1);
	if(min(f[1][0][0],f[1][0][1])>=1e6) puts("impossible");
	else fw(min(f[1][0][0],f[1][0][1]));
	return 0;
}
```

### [P4362 [NOI2002] 贪吃的九头龙](https://www.luogu.com.cn/problem/P4362 "P4362 [NOI2002] 贪吃的九头龙")

无解就是 $n \lt k+m-1$

我们发现这是一个分组问题，与 $size$ 有关，并且这个点需要被染色

大头必须吃掉 $1$，必须吃掉 $k$ 个，每种颜色都必须要有节点

这是一个类似树形背包的转移方式

我们先考虑一个简单的情况，就是 $m=2$，这显然可以黑白染色做，所有贡献只可能产生在大头之间

这让我们联想到，是否 $m \gt 2$ 时，也只用考虑大头的贡献

大头所吃掉的果子一定会将原树分割成若干棵子树

这些子树上随便选出 $m−3$ 个点与任意 $m−3$ 个小头一一对应，再对其余的点进行黑白染色

综上，只用考虑大头贡献

$f_{i,j,0/1}$ 节点 $i$ $j$ 个节点给大头吃，当前节点是否给大头吃，$ans=f_{1,k,1}$

我们就考虑当前选不选和儿子选不选即可

$$
\begin{cases}
f_{x,j,0}=\sum_{min}\,(f_{x,j-l,0}+f_{v,l,0}+w\,[m==2],f_{x,j-l,0}+f_{v,l,1})\\
f_{x,j,1}=\sum_{min}\,(f_{x,j-l,1}+f_{v,l,0},f_{x,j-l,1}+f_{v,l,1}+w)
\end{cases}
$$

这里因为每一次都会到 $k$ 所以可能会覆盖，因为每次会和上一次的自己取 $min$，所以需要用个数组先临时存一下

```cpp
const int N=310;
int n,m,k,u,v,w;
int f[N][N][2],a[N][2];
vector<pi> as[N];

void dfs(int x,int rt)
{
	f[x][0][0]=f[x][1][1]=0;
	go(it)
	{
		int v=it.first,w=it.second;
		if(v==rt) continue;
		dfs(v,x);
		//后算子树类 需要和之前的取 min
		memcpy(a,f[x],sizeof f[x]);
		memset(f[x],0x3f,sizeof f[x]);
		for(int j=0;j<=k;j++)
			for(int l=0;l<=j;l++)
			{
				f[x][j][0]=min({f[x][j][0],a[j-l][0]+f[v][l][0]+(m==2)*w,a[j-l][0]+f[v][l][1]});
				f[x][j][1]=min({f[x][j][1],a[j-l][1]+f[v][l][0],a[j-l][1]+f[v][l][1]+w});
			}
	}
}

int main()
{
	n=fr(),m=fr(),k=fr();
	if(k+m-1>n) {puts("-1");return 0;}
	for(int i=1;i<n;i++)
	{
		u=fr(),v=fr(),w=fr();
		as[u].pb({v,w}),as[v].pb({u,w});
	}
	memset(f,0x3f,sizeof f);
	dfs(1,-1);
	fw(f[1][k][1]);
	return 0;
}
```

优化写法

```cpp
#include<bits/stdc++.h>
#define pt putchar(' ')
#define nl puts("")
#define pi pair<int,int>
#define pb push_back
#define go(it) for(auto &it:as[x]) //注意加了&
using namespace std;

const int N=310;
int n,m,k,u,v,w;
int f[N][N][2],a[N][2],s[N];
vector<pi> as[N];

int fr(){ //double 不能快读！！！！
    int x=0,flag=1;
    char ch=getchar();
    while(ch<'0' || ch>'9'){
        if(ch=='-') flag=-1;
        ch=getchar();
    }
    while(ch>='0' && ch<='9'){
        x=x*10+(ch-'0');
        ch=getchar();
    }
    return x*flag;
}
void fw(int x){
	if(x<0) putchar('-'),x=-x;
    if(x>9) fw(x/10);
    putchar(x%10+'0');
}
int max(int a,int b){return a>b?a:b;}
int min(int a,int b){return a<b?a:b;}

void dfs(int x,int rt)
{
	f[x][0][0]=f[x][1][1]=0;
	s[x]=1;
	go(it)
	{
		int v=it.first,w=it.second;
		if(v==rt) continue;
		dfs(v,x);
		memcpy(a,f[x],sizeof f[x]);
		memset(f[x],0x3f,sizeof f[x]);
		for(int j=0;j<=min(k,s[x]);j++)
			for(int l=0;l<=min(s[v],k-j);l++)
			{
				f[x][j+l][0]=min({f[x][j+l][0],a[j][0]+f[v][l][0]+(m==2)*w,a[j][0]+f[v][l][1]});
				f[x][j+l][1]=min({f[x][j+l][1],a[j][1]+f[v][l][0],a[j][1]+f[v][l][1]+w});
			}
		s[x]+=s[v];
	}
}

int main()
{
	n=fr(),m=fr(),k=fr();
	if(k+m-1>n) {puts("-1");return 0;}
	for(int i=1;i<n;i++)
	{
		u=fr(),v=fr(),w=fr();
		as[u].pb({v,w}),as[v].pb({u,w});
	}
	memset(f,0x3f,sizeof f);
	dfs(1,-1);
	fw(f[1][k][1]);
	return 0;
}
```
