## Chapter 6 费用流

### 6.1 费用流

费用流是在最大流的限制上面加了一层限制得到的，每条边还有一个费用 $w(u,v)$

满足 $w(u,v)=-w(v,u)$

在保证 $\Sigma_{(s,v)\in E} f(s,v)$ 前提下，最小化 $\Sigma_{(u,v)\in E} f(u,v) \times w(u,v)$

这个问题被称为最小费用最大流

路径 $\to$ 可行流

费用流主要求解带权路径问题

### 6.2 Dinic

我们每次跑 $spfa$ 求得最短路，然后做 $dinic$ 或者 $EK$ 跑最大流

最短路的边权为改变的费用，那么每个点的最短路就是流到改点 $1$ 流量的最小代价

为什么是求最短路，我们贪心的想，这样时刻最优，累加起来就是全局最优

也可以用数学归纳法证明

$dinic$ 可以解决无负环的费用流问题，如果要解决负环就需要消圈算法辅助

$O(n^2m^2)$

注：如果要求最大费用，就把边权全部取反，然后跑的值就是负的最大费用了

#define pt putchar(' ')
#define nl puts("")

using namespace std;

const int N=5e3+10,M=1e6+10;
int n,m,s,t,u,v,w,l,ans,res,inf=2e9;
int h[N],e[M],ne[M],c[M],ep[M],idx;
int q[M],vis[N],d[N],cur[N];

int fr(){ //double 不能快读！！！！
    int x=0,flag=1;
    char ch=getchar();
    while(ch<'0' || ch>'9'){
        if(ch=='-') flag=-1;
        ch=getchar();
    }
    while(ch>='0' && ch<='9'){
        x=x*10+(ch-'0');
        ch=getchar();
    }
    return x*flag;
}
void fw(int x){
	if(x<0) putchar('-'),x=-x;
    if(x>9) fw(x/10);
    putchar(x%10+'0');
}
int max(int a,int b){return a>b?a:b;}
int min(int a,int b){return a<b?a:b;}

void add(int a,int b,int w,int l)
{
	e[idx]=b,ne[idx]=h[a],c[idx]=w,ep[idx]=l,h[a]=idx++;
	e[idx]=a,ne[idx]=h[b],c[idx]=0,ep[idx]=-l,h[b]=idx++;
}

bool spfa()
{
	int hh=0,tt=-1;
	memset(d,0x3f,sizeof d);
	memcpy(cur,h,sizeof cur); //注意清空
	q[++tt]=s,d[s]=0,cur[s]=h[s];
	
	while(hh<=tt)
	{
		int x=q[hh++];
		vis[x]=0;
		
		for(int i=h[x];~i;i=ne[i])
		{
			int j=e[i];
			if(c[i] && d[j]>d[x]+ep[i])
			{
				d[j]=d[x]+ep[i];
				if(!vis[j]) q[++tt]=j,vis[j]=1;
			}
		}
	}
	return d[t]!=0x3f3f3f3f;
}

int find(int x,int ltf)
{
	if(x==t)
	{
		res+=d[t]*ltf;
		return ltf;
	}
	
	vis[x]=1; //判环
	int rest=ltf;
	for(int i=cur[x];~i && rest;i=ne[i])
	{
		cur[x]=i;
		int j=e[i];
		if(vis[j]) continue; //判环
		if(c[i] && d[j]==d[x]+ep[i])
		{
			int k=find(j,min(c[i],rest));
			if(!k) d[j]=inf; //改成inf 是跑最短路
			else c[i]-=k,c[i^1]+=k,rest-=k;
		}
	}
	vis[x]=0;//清空，下次还要跑
	return ltf-rest;
}

int dinic()
{
	ans=res=0;
	int flow;
	while(spfa())
		while(flow=find(s,inf)) ans+=flow;
	return ans;
}

int main()
{
	memset(h,-1,sizeof h);
	n=fr(),m=fr(),s=fr(),t=fr();
	for(int i=1;i<=m;i++)
	{
		u=fr(),v=fr(),w=fr(),l=fr();
		add(u,v,w,l);
	}
	dinic();
	fw(ans),pt,fw(res);

	return 0;
}

### 6.4 最大权不相交路径

[题目](https://www.luogu.com.cn/problem/P4013 "题目")

第一问显然，每个点有限制，拆点即可，边容量全 $1$，费用就是点权，最大费用最大流即可

### 6.7 problem

[题目](https://www.luogu.com.cn/problem/P1251 "题目")

对于每天，我们要做的操作是：

接受之前慢/快洗好的毛巾，买新毛巾

把旧毛巾送去洗/流到下一天

每个操作都对应一个代价，然后是天与天之间的转移，我们想到最大流/费用流

我们发现这两个操作是分开的，所以我们拆点，相当于是一天的新毛巾需求和旧毛巾剩余

对于入点，接受之前的毛巾，就是从之前天的出点向它连边，容量正无穷

新买毛巾，我们可以类比之前最小生成树，新建基站等操作，从 $s$ 向他连边，同样容量正无穷

对于出点，流到下一天，那还是旧毛巾，向下一天的出点连边正无穷，费用 $0$

送去洗等价于之后拿，同入点

然后每天必须要恰好剩 $r_i$ 条新毛巾给这天用，所以入点还要向 $t$ 连边容量  $r_i$

第 $i$ 天有 $r_i$ 条旧毛巾，所以 $s$ 还要向出点连边容量 $r_i$

最大流显然为 $\Sigma r_i$ 所以此题为最小费用最大流

[题目](https://www.luogu.com.cn/problem/P3358 "题目")

注：题目意思应该是左闭右开

看到这个限制，然后又有权值，我们感觉可能是最大费用可行流

如果把线段长度和不被覆盖 $K$ 次一起搞的话有点麻烦，我们先分开

我们考虑 $spfa$ 最长路的形成过程，将所有线段分成 $k$ 层（不够就能分多少分多少），每层内部无交集

当前第 $i$ 层，$i\geq 1$，那么第 $i$ 层的线段一定与第 $i-1$ 层的线段有交集，否则放在上一层求得最长路更优，矛盾。

所以我们叠 $k$ 层，每次求得最长路，累加起来就是最优，证明可类比 $SAP$

然后将最长路和权值分开，因为每一层内部还要跑，我们干脆拆点，不然不好限流一条线段只能用一次，顺便把线段长度的权值转上去了

[题目](https://www.luogu.com.cn/problem/P4009 "题目")

假设没有油量的限制，就是裸的最小费用流

我们考虑如何体现这个油量，我们不妨分层图

将原图分成 $K+1$ 层，第 $0$ 层表示满油，每次向下一层走，消耗 $1$ 油量

这样就满足了条件 $1\;2$

然后是条件 $3$，注意是强卖强卖，所以我们不管在哪一层，都会回到 $0$ 层，费用 $A$
