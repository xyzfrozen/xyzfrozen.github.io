主要是复习一下字符串

# 定义 

$pre(S,i)$  $S$ 的前 $i$ 个字符构成的前缀

$suf(S,i)$ $S$ 的后 $i$ 个字符构成的后缀

$\text{border}$ ：满足 $pre(S,i)=suf(S,i)$ 的 $i$，且 $i\in [1,|S|-1]$，记为 $T=S[1,i]\,\text{bel}\,S$

$\text{period}$ ：满足 $\forall\,i\in[1,|S|-p],s[i]=s[i+p]$ 的 $p$，且 $p\gt 0$

设 $max-border=MS(S)$

# 性质

1. 若 $pre(S,p)$ 为 $\text{border}$ $\Leftrightarrow$ $|S|-p$ 为 $period$

​	因为 $\forall i\in[1,|S|-(|S|-p)]]\,s[i]=s[i+|S|-p]$

应用：最短的字符串 $T$，满足 $S$ 为 $nT$ 的子串，$|T|=|S|-|MS(S)|$

前面的就用 $T$ 拼，后面由于 $\text{border}$ 的性质，可以直接把 $|T|$ 拼在后面

2. $\text{border}$ 的传递性：

	若 $t\,\text{bel}\,r$，$r\,\text{bel}\,S$，则 $t\,\text{bel}\,S$

	若 $t\,\text{bel}\,S$，$r\,\text{bel}\,S$，$|r| \gt |t|$ ，则 $t\,\text{bel}\,r$

$pre(S,|MS(S)|),pre(S,|MS(MS(S))|,\ldots$ 为 $S$ 的全部 $\text{border}$

# problem

**P7114 [NOIP2020] 字符串匹配**

先不管 $F$ 的限制，直接枚举 $C$ 的长度，然后考虑到 $i\mid |S|-|C|$，至多 $\log |S|$ 个， $Hash$ 暴力判断一下即可

总复杂度 $O(|S|\log |S|T)$，$T$ 为一次判断 $Hash$ 的时间，至多为 $|S|\log |S|$，调和级数级别，当然远远不到

我么考虑优化

还是枚举 $C$，设 $AB=M$，$S-C=T$

考虑到最小 $\text{period}$ ，设 $p=|T|-|MS(T)|$，合法当且仅当 $p\mid |M| \mid |T|$

我们枚举 $M$ 的长度和 $i$，$O(1)$ 统计合法的 $A$

具体还要维护一个前缀后缀的 $F$，维护一个桶，$t_j$ 表示当前可作为 $A$ 的，且字符数量为奇数的数量 $\geq j$ 的数量

```cpp
#include<bits/stdc++.h>
#define pt putchar(' ')
#define nl puts("")
#define pi pair<int,int>
#define pb push_back
#define go(it) for(auto &it:as[x])
using namespace std;

const int N=(1<<20)+10;
int n;
int kmp[N],pre[N],suf[N],t[30];
char s[N];

int fr(){
    int x=0,flag=1;
    char ch=getchar();
    while(ch<'0' || ch>'9'){
        if(ch=='-') flag=-1;
        ch=getchar();
    }
    while(ch>='0' && ch<='9'){
        x=x*10+(ch-'0');
        ch=getchar();
    }
    return x*flag;
}
void fw(int x){
	if(x<0) putchar('-'),x=-x;
    if(x>9) fw(x/10);
    putchar(x%10+'0');
}
int max(int a,int b){return a>b?a:b;}
int min(int a,int b){return a<b?a:b;}

void solve()
{
	scanf("%s",s+1);
	n=strlen(s+1);
	for(int i=2,k=0;i<=n;i++)
	{
		while(k && s[k+1]!=s[i]) k=kmp[k];
		if(s[k+1]==s[i]) k++;
		kmp[i]=k;
	}
	
	memset(t,0,sizeof t);
	for(int i=1;i<=n;i++)
		pre[i]=pre[i-1]+(((++t[s[i]-'a'+1])&1)?1:-1);
	memset(t,0,sizeof t);
	suf[n+1]=0;
	for(int i=n;i;i--)
		suf[i]=suf[i+1]+(((++t[s[i]-'a'+1])&1)?1:-1);
	
	memset(t,0,sizeof t);
	long long ans=0;
	for(int i=pre[1];i<=26;i++) t[i]++;
	for(int len=2;len<n;len++)
	{
		ans+=t[suf[len+1]];
		for(int i=(len<<1);i<n;i+=len)
		{
			int p=i-kmp[i];
			if(!(len%p) && i/p>1)
				ans+=t[suf[i+1]];
		}
		for(int i=pre[len];i<=26;i++) t[i]++;
	}
	printf("%lld\n",ans);
}

int main()
{
	int T=fr();
	while(T--) solve();

	return 0;
}
```
