[P5381 [THUPC2019\] 不等式 - 洛谷 | 计算机科学教育新生态 (luogu.com.cn)](https://www.luogu.com.cn/problem/P5381)

当我们发现一个点的大小不在是 $1$ 的时候，但是求的东西可以转化为 $\geq size$ ，也可以直接分裂

```cpp
void split_sz(int now,int size,int &l,int &r)
{
    if(!now) return void(l=r=0);
    if(Ls(now).sz<size) l=now,split_sz(tr[now].rs,size-Ls(now).sz-tr[now].cnt,tr[now].rs,r);
    else r=now,split_sz(tr[now].ls,size,l,tr[now].ls);
    chf(now);
}
```



[P3960 [NOIP2017 提高组\] 列队 - 洛谷 | 计算机科学教育新生态 (luogu.com.cn)](https://www.luogu.com.cn/problem/P3960)

平衡树维护区间，此时加入裂点操作

```cpp
void split_node(int now,int sz)
{
	if(sz>=tr[now].R-tr[now].L+1) return;
	int r=tr[now].R;
	tr[now].R=tr[now].L+sz-1;
	tr[now].rs=merge(add(tr[now].L+sz,r),tr[now].rs);
}
```

时空复杂度都稍微高了一点，但是 $\Delta$ 还是在 $O(\log n)$ 级别的
